\section*{Inventory and correction}
There are 93 tracked Lean files. Before this change, 33 inherited no
\mono{lean-toolchain}. The new root pin is \mono{leanprover/lean4:v4.34.1},
while local pins still win. After the change, 92 files resolve to Lean 4.34.1
and the binary-genus-2 module retains Lean 4.24.0.

The new \mono{tools/audit\_lean\_evidence.py} reads committed files even in
sparse checkouts. It checks each pin, scans Lean code outside comments and
strings for forbidden proof tokens, and compares dedicated Lean receipt
source SHA-256 values and toolchain claims. The observed result was
\textbf{0 missing pins, 0 files with forbidden tokens, and 13/13 matching
source receipts}. CI now runs this static check on relevant changes. A pin,
lexical scan, or matching receipt is not a kernel theorem verdict.
