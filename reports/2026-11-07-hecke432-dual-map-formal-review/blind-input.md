# Blind algebra input

Work independently from the equations below. Do not read repository history,
producer Lean source or proof text, archived reports, receipts, or another
reviewer's output. Use exact algebra and give a worked derivation and concrete
nearby false cases.

For a commutative ring element X, investigate

`(X³ − 16)(X³ + 128)² − (X³ − 64)³ = 432 X⁶`.

For a field with X nonzero and `Y² = X³ − 16`, investigate whether

`(Y (X³ + 128) / X³)² = ((X³ − 64) / X²)³ + 432`.

Determine what happens if 128 changes to 127, if the source-curve equation is
dropped, and at X = 0. State exactly what these equations alone establish.
