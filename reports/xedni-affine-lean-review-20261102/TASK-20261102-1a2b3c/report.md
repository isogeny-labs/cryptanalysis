# Blind algebra review: algebra-and-exceptions

Verdict: **holds**, for the mathematical statement with the hypotheses below. This is a blind derivation; it does not assess any producer proof, implementation, or experimental result.

Let all vectors have common finite dimension `n`, all coefficients be integers, and `q` be a positive integer. Put

`K = {v in Z^n : B_j · v = 0 for every j, and v_k ≡ 0 (mod q) for every k}`.

`K` is an additive subgroup of `Z^n`: dot products are additive and `q Z^n` is closed under integer scalar multiplication and addition. If each `D_i` belongs to `K`, then every finite integer combination `S = Σ_i c_i D_i` belongs to `K`. Consequently, for `x = u + S`, every row satisfies

`B_j · x = B_j · u + Σ_i c_i (B_j · D_i) = B_j · u`,

and every coordinate satisfies

`x_k - u_k = Σ_i c_i D_i,k ∈ q Z`, hence `x_k ≡ u_k (mod q)` and, with `q > 0`, `x_k % q = u_k % q` under the usual Euclidean remainder convention.

The same conclusion holds after any *integer* recombination `E_l = Σ_i a_li D_i`: each `E_l ∈ K`, so `u + Σ_l t_l E_l` has the invariants for arbitrary integers `t_l`. The recombined span is contained in the original span; equality of spans additionally requires a suitable invertible integer change of generators (for example, a unimodular square transformation), and is not needed for preservation. The exact set of candidates generated by the original directions is `u + span_Z{D_i}`, contained in `u + K`; equality with `u + K` requires the directions to generate `K`.

## False controls and premise checks

| Input (`n=1`, `u=0`, `c=1`) | Row change | Residue change (`q=2`) | Conclusion |
| --- | ---: | ---: | --- |
| `B=1`, `D=1` | `B·D=1` | `D % 2=1` | Both premises fail and both claimed invariants fail. |
| `B=0`, `D=1` | `B·D=0` | `D % 2=1` | Row invariant holds; residue invariant fails. |
| `B=1`, `D=2` | `B·D=2` | `D % 2=0` | Residue invariant holds; row invariant fails. |

For preservation **for every** integer coefficient choice, each direction must lie in every row kernel and in `q Z^n`: choose one coefficient equal to `1` and all others `0` to recover each premise. For a single fixed candidate, the individual direction premises are stronger than necessary because contributions may cancel; the necessary and sufficient conditions are `B_j·S=0` for each row and `S_k ∈ q Z` for each coordinate. The kernel premise is needed for row preservation; the divisibility premise is needed for residue preservation. `q=1` makes the residue premise automatic. Empty row or direction families, or dimension zero, yield the corresponding vacuous statements. The positive-modulus hypothesis supplies the stated remainder interpretation; the subgroup argument itself only needs a defined modulus subgroup.

No converse about optimization, feasibility beyond these invariants, or the behavior of a particular recombination algorithm follows from this algebra alone.
