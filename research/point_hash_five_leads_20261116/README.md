All five paths are implemented behind explicit options in the native Rust
collector and `solve-hashed-optimized`, including each individual arm and the
combined arm. Default options preserve the joint prepared control. This is a
producer implementation/development receipt, not independently signed standing.

|---|---|---|---|

| 2: batch complements | One ordinary inversion per chunk; checked exceptions | Exhaustive F17/F5 equality, chunk order/limits and whole seeded certificates | Price batching, products and unused tails |
| 3: graph collection | Weighted forest and useful cycle dependencies | Dense dependency differential, complete solves and strict v1 N+1 rejection | Relation yield, memory and sparse recovery cost; early-stop v2 remains separate |

These are implemented paths with producer correctness controls, not measured
performance improvements. [pcc:unverified]
