# Shared degree-13 function-build experiment

The degree-13 `H.build([13])` output is computed over the same source irrespective of the later finite field. The frozen experiment tests object reuse across p8597 and p12197, retaining the exact source and checked prefix receipts. Four separate checked-Sage processes run in fixed sequence: shared build with order (8597,12197), separate builds with reverse order, separate builds with first order, shared build with reverse order. Each process must recompute all visited degree-13 fibers, signed prefix cancellations and rational/Fq rank paths and match the frozen prefix receipt exactly. In shared mode, one `(funcs,jfun)` object is passed to both `Reduced` instances; in separate mode, `H.build([13])` runs before each instance. Canonical serialized build outputs must have the same SHA-256 across all six invocations.

Save `./sage --runtime-info` before measured runs. Each run uses `gtimeout 1800 ./sage -python` and records build, per-prime setup/fiber/search/rank wall phases, operation counts, peak RSS, source/checksum identities and status. Preserve failures and zero-yield prefixes. The comparison is a two-prime reusable-setup experiment on a shared host, with order alternation but without an isolation-tier speedup gate. Candidate ID and single-target online time remain null.
