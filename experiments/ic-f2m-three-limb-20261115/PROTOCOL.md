# Frozen exploratory binary-field component panel

Publish this protocol and both source variants before generating fixtures20..24.
This panel measures the field multiply dependency chain only. It is a kernel
selection diagnostic; it cannot establish full relation throughput, online IC
performance, novelty or a same-point IC/rho comparison.

Compile the same isolated crate twice with cargo build --release --locked,
using separate target directories, default features and f2m-karatsuba3.
The crate imports the actual suite field module. Record source hashes, rustc,
compiler flags and executable hashes. Run the full field unit tests first.
The default is the existing nine-product three-limb implementation; the
candidate uses six products and coefficient reconstruction. Other widths and
reduction are controls and retain identical source.

Cases are the existing field definitions at degrees113,131,155,163,233.
The three-limb cases131/155/163 are primary component cases;113 and233 control
the two-/four-limb paths. For each degree run fresh fixture indices20..24.
main.rs freezes the xorshift seed formula, initial element and multiplier;
record both elements in every row. Time exactly1,000,000 dependent public
field multiplications, including runtime feature dispatch, scratch clearing,
reduction and returned-element handling. Construction, one independent
schoolbook check and final checksum encoding are outside this component timer.
No full-attack accounting is implied. Do not substitute a throughput batch.

Use one CUDA-capable allocation with four requested CPUs,8GiB,oneL4 and a
900-second cap. The kernel is CPU-only. Pin one allowed CPU. Alternate backend
order with fixture parity. Before and after each pair run a default-binary
131-bit calibration chain at fixture0 with the same iteration count. Keep raw
wall times, exit status, checksums, hardware/affinity/cgroup/NUMA observations
and context switches where available. Keep every failed pair and regression.
Checksum agreement is a producer consistency check, not independent execution
verification. Apply a0.85..1.15 calibration ratio diagnostic without deleting
rows. Report individual ratios, medians and observed ranges per degree.

The known Modal gVisor allocation lacks the previously required placement
receipt. This exploratory panel never populates qualified timing fields and
its benchmark record remains invalid for promotion. Record any additional
missing controls. Never use these kernel ratios as full IC performance or as
a reason to change the production default. Controlled host timing and full
suite/relation integration remain separate open requirements.
