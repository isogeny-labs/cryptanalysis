# Regular affine reduction on known-relation lifts

The thirteen exact known-relation lifts admit 54 consecutive rational additions from their recorded rational point `T` to the multiples needed for `P1` and `P2`. Every step has integral input and output coordinates at its row's prime, a unit slope denominator, and the same result after reduction as finite-field addition. The steps consist of 13 tangents and 41 chords. The source is fixed by SHA-256 in `protocol.json`; `python3 run.py` independently recomputes and asserts each check, with all step-level observations in `result.json`.

The generic mathematical statement is: for a commutative ring `R`, field `S`, and ring homomorphism `f : R →+* S`, an affine chord or tangent with unit denominator in `R` has slope and output coordinates that commute with `f`. The written proof is substitution into the Weierstrass addition formulas. A unit `d` satisfies `f(d) f(d⁻¹)=1`, so the mapped rational slope equals the quotient of mapped numerator and denominator. The output coordinates are polynomials in the inputs and slope, and ring homomorphisms preserve those polynomials.

The Lean chain theorem transfers a path of curve points and regular affine steps, and the group-law theorem identifies its reduced endpoint with a group multiple. The local-integer modules supply the prime-local ring and direct `ZMod p` residue map, including fraction reduction. All 134 recorded rational coordinates have checked denominator-admissibility proofs, all 67 recorded multiples have checked curve equations and prime-local `CurvePoint` definitions, and all 54 recorded additions have checked `RegularStep` proofs assembled into 13 `RegularChain` proofs. All 13 recorded short curves have checked finite-field ellipticity and group-law consequences. The next proof step is to identify the exact multiplier in each chain, connect selected endpoints to their recorded public points, and extend point reduction through infinity and vertical additions.

## Reproduction

From this directory, run `python3 run.py`, `python3 generate_coordinate_certificates.py --check`, `python3 generate_curve_equation_certificates.py --check`, `python3 generate_recorded_regular_steps.py --check`, `python3 generate_finite_group_chains.py --check`, `lake build AffineReductionBridge`, `lake build RegularChainReduction`, `lake build RegularGroupLaw`, `lake build PrimeLocalReduction`, `lake build LocalZModReduction`, `lake build RationalLocalWitness`, `lake build CoordinateCertificates`, `lake build RationalCurveBridge`, `lake build CurveEquationCertificates`, `lake build RationalRegularStep`, `lake build RecordedRegularSteps`, and `lake build FiniteGroupChains`. The Lean version is pinned in `lean-toolchain`, mathlib in `lake-manifest.json`; the corresponding `build-output*.txt` files record the theorem builds and `#print axioms` output. The replay and certificate generators need only the Python standard library and the source JSON at the sibling path named in the protocol.
