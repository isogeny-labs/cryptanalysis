# Versioned ephemeral sign lookup

The first frozen symmetric-cache arm constructs a negative triple for every signed query whose first sign is -1. The known-control replay preserved rows and cache size but showed an exploratory wall-time regression. This predeclared second implementation keeps the same four-entry persistent triple cache, and for each later-four source support computes its four opposite-sign triples once into an eight-value ephemeral lookup. It preserves the exact query and row order. Charge all four setup negations, including the final partially queried support.

After the first replay finishes, pair the first symmetric arm and this micro-lookup arm on the same frozen nine source journals, alternating arm order. Freeze the new source and runtime receipt before replay. Require exact rows, probes, ranks, anchor logs and cache counts. Audit the per-source negation identity: `old_neg_calls - micro_neg_calls = negative-first-sign probes - 4 × entered later-four supports`, with `negative-first-sign probes = 16 floor(step_probes/32) + min(step_probes mod 32,16)` and `entered supports = ceil(step_probes/32)`. Additions and persistent cache entry counts must be identical. Record wall time as exploratory and retain the old arm's slower result.
