The independent Sage audit used a different four-plus-three split. It verified all 320 source equations, matched every canonical support/sign/row tuple, rechecked point equations, operation counts, caps, final ranks, and the anchored log replays. A separate prefix derivation grouped rows by their largest source index; an independent Sage matrix audit checked all 320 prefix ranks and the first rank-39 source counts in the table. Those prefix counts describe reachability from the sealed full-pool rows; they are **derived**, not measured live stopping intervals.

This retrospective mechanism result establishes seven-source cancellation as a complete class-log rank source on this panel. The next experiment is a prospectively frozen **live support-seven rank-stop collector** on disjoint classes.
