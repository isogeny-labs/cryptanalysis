# Deterministic shuffled degree-13 source order

The frozen p8597 and p12197 direct-plus-base matrices each have rational rank 39. This experiment asks how many degree-13 source fibers a deterministic source order needs before a support-at-most-four outside-trace cancellation adds the missing rational dimension. It uses the previously completed full 40-source receipts, so the 256-order distribution is a retrospective scheduling diagnostic, not a holdout result.

For repetition `rep` from 0 through 255, sort indices 0 through 39 by SHA-256 of the UTF-8 string `hecke-d79-order-v1|p|rep|i`, breaking a digest tie by index. Repetition 0 is chosen for fresh replay before inspecting its result. The ascending order is the frozen comparator. The baseline is all degree-2/5 base rows plus all verified direct support-at-most-four rows. Construct its exact rational one-dimensional nullspace from 39 selected rows; check every baseline row against it. A Hecke candidate is rank raising exactly when its row has nonzero pairing with this null vector. For each permutation, stop at the first prefix containing all source indices of any rank-raising candidate. Keep all 256 source counts, the active candidate IDs, and the ascending count.

For repetition 0 only, load the content-addressed degree-13 function artifact through the v2 cache interface, prohibit `H.build`, and freshly lift sources in permutation order. Check every visited fiber against the hash-pinned full receipt, enumerate every newly completed signed support-one through support-four combination, verify its group equation and class row, compare the candidate set with the full receipt subset, and recompute the rational rank at each prefix. Stop at the first rank-40 prefix. Save launcher runtime information and all phase counts/times. Cap each Sage job at 1,800 seconds. The stage work is reusable relation preparation; `candidate_id` and target-online time remain null.
