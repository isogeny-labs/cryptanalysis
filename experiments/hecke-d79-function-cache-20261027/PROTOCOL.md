# Cross-process degree-13 function cache protocol

Serialize one checked `H.build([13])` output as canonical compact sorted-key UTF-8 JSON with exact rational numerators and denominators, source SHA-256, degree, all 28 function coefficient maps, j-function coefficient map, x0 and cusp. Name the immutable artifact by SHA-256 of its complete canonical bytes. Reject a noncanonical encoding, missing/duplicate key, noncanonical rational, wrong source/degree, mismatched filename or digest, malformed cusp, or unexpected function set before constructing Sage objects. Record build, encoding and load phases separately.

After the artifact is frozen, one independent checked-Sage process rebuilds `H.build([13])` and compares every rational coefficient and the previous six-invocation function digest. Four separate checked-Sage processes load the artifact in fixed order p8597,p12197,p12197,p8597, never calling `H.build`; each replays all visited prefix fibers, signed cancellations and QQ/Fq rank paths using the frozen prefix runner and shared-runner source. A corrupt-byte control must fail the loader's digest check before JSON decoding. Save `./sage --runtime-info` before measured work and cap every Sage command at 1800 seconds. Preserve every status, stdout/stderr, artifact hash, phase time and RSS.

The cache is reusable setup for the two-prime workload. Host timings are exploratory and separate from single-target online time; candidate ID and online time remain null. No new mathematical rank theorem is introduced; exact prefix matrices retain their checked Lean evidence.
