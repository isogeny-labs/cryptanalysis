# Validated degree-13 function cache interface and fallback

Version the decoder as v2 with explicit `CacheValidationError` exceptions for all artifact validation, including under optimized Python. Keep the v1 content-addressed artifact immutable. The interface receives a pinned source module, expected artifact and function digests, and a strict or fallback policy. A valid artifact returns `CACHE_HIT` with zero `H.build` calls. A missing or invalid artifact under fallback performs exactly one fresh `H.build([13])`, validates the function digest and records `FALLBACK_MISSING` or `FALLBACK_INVALID` and the reason; it does not overwrite the pinned artifact. Strict mode rejects missing/invalid artifacts with zero builds. Runtime failures other than recognized validation errors propagate.

Freeze the valid, missing and single-byte-invalid fixture paths and six run cases before execution. Run cached p8597 and p12197 replays, missing p8597 and invalid p12197 fallbacks, and strict missing/invalid controls. Every successful resolution reruns the visited source-prefix fibers, cancellations and rank paths against pinned receipts. A separate checked-Sage process rebuilds the functions and compares every v2-decoded coefficient. Exercise malformed rational and source metadata under Python optimization to verify explicit exceptions. Save `./sage --runtime-info`, use `gtimeout 1800` for all Sage jobs, and retain source/build counts, phase timings, RSS, output hashes and failures. The experiment concerns reusable setup, not target online time.
