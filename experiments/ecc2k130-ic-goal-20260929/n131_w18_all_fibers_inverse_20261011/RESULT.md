# One N131 inverse-trace circuit covers all four raw fibers and 32 terminal states

An exact 128-choice terminal residual selector extends the W18 inverse-trace point-decomposition circuit to **all four raw preimages of one public subgroup point** and every state of the previously frozen 32-state terminal pool. The public formula has **200,192 variables and 134,886 AND gates**, only 10,505 variables and 5,817 AND gates above the single-terminal [inverse-trace baseline](../n131_w18_inverse_trace_terminal_20261011/RESULT.md). The [constructed control](control_result.json) satisfies every clause and native-XOR row; [independent checked Sage](sage_audit_result.json) verifies the four raw preimages and all 128 control and public residuals on the exact curve.

The curve is `y²+xy=x³+1` over `GF(2)[t]/(t^131+t^13+t²+t+1)`, curve ID `EC1N131Ckb1heb5f1998f20b`, subgroup order `680564733841876926932320129493409985129`. The public workload remains `cc09e7eb202a` on the same previously unseen point. Online computation starts by multiplying that point by `4⁻¹ mod r`, then adds the four curve-specific 4-torsion offsets `O`, `(0,1)`, `(1,0)`, `(1,1)` to obtain its raw preimages. For each raw point it subtracts each of 32 target-independent signed terminal points and computes the reciprocal x-coordinate. All 128 resulting values are distinct and avoid the exceptional x-coordinates 0 and 1. The circuit selects exactly one residual, keeps eight W18 seed-212 source pairs free at rotations `0,16,...,112`, enforces inverse-trace rationality for both endpoints, and requires the eight pair codes to be distinct from each other and from the selected terminal code. The four preimages, terminal state, pair masks, pair-output coordinates, S3 intermediates, and branch bits were unpinned in the public search.
