## Exact source and target conditions

An edge uses canonical W23 mask `a`, `b=a XOR 898618`, field coordinates `w(mask)=mask<<1` in `GF(2)[t]/(t^131+t^13+t²+t+1)`, and product `p=ab=a²+sa`. The shared version enforces `pv=1`, `Tr(a)=Tr(av)=Tr(sv)=0` with a single inverse witness `v`. These constraints ensure that both endpoints are nonzero and satisfy the two endpoint inverse-trace conditions. The comparison version enforces those two endpoint inverses separately. Each pair output `z=1/x(P+Q)` satisfies `(1+h²)z²+pz+h²=0`, where `h²` is the square of the seed half-trace. Five S3 equations use rotations `(0,18,36,54,72,90)` and balanced links `(0,1,6),(2,3,7),(4,5,8),(6,7,9),(9,8,10)` to constrain all six outputs to one raw target reciprocal. The public point is `(877610862732227974378969808549299291499,2063336771837286479337213121437715536874)`; its standard reciprocal is `770794657550069419943936485965613853151`.

The independent checked-Sage [fixture producer](prepare_sage.py) selected six disjoint-column edges from the prior W23 census, reconstructed twelve curve lifts, formed six pair sums and their balanced group sum, and checked the pair-output quadratic. Its [fixture](fixture.json) contains the exact masks, columns, source inverses, pair outputs, middle points and target. The [read-only verifier](verification.json) rechecks the frozen hashes, six source laws, five S3 links, twelve distinct columns, both complete control assignments, and both public point conversions. It reports **568,738 control clauses and 88,306 control XOR rows checked**. The successful run command was `./sage -python experiments/ecc2k130-ic-goal-20260929/n131_w23_sixpair_shared_circuit_20261017/run_v3.py`; the verifier was run with `python3`.

The constructed control passes the distinct-column rule. The public circuit currently leaves that rule to a later witness check or lazy collision cuts, so a SAT assignment to the public formula would require independent source-column and group replay before counting as a relation. This is the next implementation gate, followed by an unpinned public solve under the one-worker, 600 s, 4 GiB envelope. The existing N41 six-pair public group join is the same-topology relation control; N131 source-bound search cost remains to be measured. Full IC rank, target descent, and paired rho accounting remain the subsequent pipeline gates.
