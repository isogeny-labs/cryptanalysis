# Bounded-fill XOR projection for the N131 d13/m12 point-decomposition gate

An exact cap-64 projection eliminates 119,182 CNF-private XOR variables from
the frozen N131 ordinary public-point formula while retaining 902,292 XOR
literal occurrences. The earlier unrestricted projection retained 4,033,665
XOR literal occurrences. An independent row-operation replay checked every
eliminated pivot and every residual row; a planted N131 assignment passed the
projected formula, reverse lift, original formula, and exact equality with its
frozen full assignment. The ordinary-point CryptoMiniSat query reached its
540-second cap with status `CENSORED_TIME` and no model line.

The instance is the exact degree-131 Koblitz challenge curve
`EC1N131Ckb1heb5f1998f20b`. The d13/m12 encoding has 12 summands and the
phi-domain factor base has 1,083,108 actual usable points before folding and
4,134 folded columns. This experiment reuses the frozen ordinary public point
with workload ID `3c1992b7c92f`; it is a solver-stage method check on that
point. The frozen original XCNF is SHA-256
`91ed7b49e8a8e8637f79c94cdb568ece415f32359d82425d4369fd829481622e`.

For each CNF-private variable, the projector selects the shortest containing
XOR row. It eliminates the variable only when adding that pivot to each other
containing row would produce a row of at most 64 variables. A skipped variable
remains available to the solver. The cap applies to **new** rows; an inherited
original row may be wider. The lift certificate records the exact pivot row
and parity in elimination order. Reverse order reconstructs eliminated values
from a projected assignment. The [proof map](PROOF_MAP.md) gives the Boolean
row-addition and arbitrary-list pivot lemmas, checked in Lean 4.34.1; the
bridge from the Python certificate to a formal XCNF semantics remains open.

Both new formulas start from 232,244 variables and 171,278 XOR rows. The
ordinary cap-64 projection took 8.735 seconds in this local run. These wall
measurements are algorithmic diagnostics on a shared host; formula size and
certificate equality are the reproducible comparison here. The
[independent planted audit](planted_cap64/independent_audit.json) replayed
402,292 row additions and confirmed the reverse lift reproduces the frozen
full model. The [independent ordinary audit](public_cap64/independent_audit.json)
replayed 336,682 row additions and compared the complete residual XOR
multiset and every mapped CNF clause with the emitted bytes.

Both runs used one CryptoMiniSat worker, the same projected formula and seed,
and a 4 GiB combined RSS stop rule. Their frozen
[540-second protocol](public_cap64_protocol.json) and
[120-second protocol](public_cap64_gauss_protocol.json) bind the solver flags,
input hashes, runtime receipt, and runner. The
[R1 raw output](public_cap64_stage_R1/cryptominisat.stdout.txt) records that
CryptoMiniSat excluded a 38,213 × 80,536 XOR component under the smaller
matrix limits. The [preflight raw output](public_cap64_gauss_stage_R1/cryptominisat.stdout.txt)
records that it admitted that component within the memory cap and reached
6,176 conflicts before the 120-second stop. This short preflight establishes
matrix admission and resource use; it does not estimate relation yield or a
single-target speedup. Ordinary-query yield and useful rank remain open until
a model passes the prepared [independent relation auditor](audit_sat_model_and_relation.py).

The projection source, emitted XCNF, variable maps, lift rows, SHA-256
receipts, and raw solver outputs are retained in this directory. The saved
`sage_runtime_info.json` was generated by the repository `./sage
--runtime-info` launcher before measured work. `lean PrivateXorPivot.lean`
passed from this directory and its output is saved in
[lean_check.stdout.txt](lean_check.stdout.txt); `#print axioms` reported no
axioms for all three theorems. The seven Python modules parsed successfully.
`go vet ./...` and `go test ./...` passed from `orchestrator/`; the first
sandboxed test attempt could not bind the local `httptest` listener, and the
authorized loopback rerun passed.

The next selection gate is a paired smaller-field full-pipeline control for
the same bounded projector, including ordinary-query yield and rank. For
N131, the present trace favors testing target-conditioned leaf constraints
over simply increasing the Gaussian matrix limits: the admitted large matrix
fits memory but produces only a short, expensive search trace. A later N131
query must use a previously unseen ordinary target and independently replay
its factor-base decomposition before relation collection and single-target
online comparison proceed.
