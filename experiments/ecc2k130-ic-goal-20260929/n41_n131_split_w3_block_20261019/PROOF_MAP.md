# Proof map for the width-three case split

The structural case partition is formalized in `SplitBlock.two_width_two_cases_cover_width_three` in `SplitBlock.lean`. It states, for an arbitrary type of assignments, a natural-number left-code map, and a root predicate, that exclusion on codes `0..3` and `4..7` excludes codes `0..7`. The theorem uses no field or curve assumptions; those belong to the two case-specific input and certificate checks.

The row-span soundness step is `BlockCertificate.constant_one_block_certificate_sound` in the versioned `n41_w11_block_macaulay_20261019/BlockCertificate.lean`. Its hypotheses are a commutative ring, `1 ≠ 0`, and a pointwise constant-one identity formed from polynomial equation rows. `verify_public.py` replays each selected row over the frozen Boolean input, and `audit_sage.py` independently reconstructs the coordinate equations over GF(2^131). The first half uses the prior archived audit and verifier. These finite artifacts are linked to the exact source-code representation and public point by their frozen protocol hashes.

`SplitBlock.lean` was built with `elan run leanprover/lean4:v4.34.1 lean ...`; `lean.stdout` records `#print axioms` reporting no axioms. The existing row-span theorem was built with the same pinned Lean toolchain and its own `#print axioms` output. No Lean declaration here formalizes the full binary-field curve, the resultant construction, or the exact 131-coordinate input file. The full concrete bridge remains the independently checked Sage input audit and the Python certificate replay. If the second case caps, the width-three exclusion remains open even though the partition theorem is proved.
