# Target-conditioned Macaulay certificates for four-code W11 blocks

A degree-six Boolean Macaulay row span **rejected five empty blocks of four free left codes each** while retaining the block containing the independently verified public-relation component `(253,63)`. Each block kept all ten right-code bits free. The producer evaluated all 24,576 code pairs in six frozen cells; an independent checked-Sage truth-table reconstruction reproduced every value and replayed all five constant-one certificates. Degree-four and degree-five rows rejected none of the six cells. This is an exact target-conditioned block exclusion on the N41 panel, with `candidate_id: null` until a complete IC pipeline exists.

The curve is `EC1N41Ckb1h7d5e80d3c4d0` over `GF(2)[u]/(u^41+u^3+1)`, with `y²+xy=x³+1`, subgroup order `549756390943`, and cofactor four. The frozen W11 source uses seed element `112`, rotations `(12,24)`, ten free code bits per pair, and the exact 13-term two-product eliminant `H(p,q)` from the preceding result. The positive residual is the public target after its archived three-pair suffix. Target row 1 is the first frozen ordinary residual in the same 25-point panel. Left-code blocks `[0,3]`, `[252,255]`, and `[512,515]`, target rows `[0,1]`, degree levels `[4,5,6]`, and the one-worker 180 s/4 GiB cap were frozen before the producer ran.

Because `p` and `q` are binary-linear in their code bits, every term of `H(p,q)` has squarefree Boolean degree at most four. The producer expanded the left block's two free bits jointly with all ten right bits, yielding 12 Boolean variables. For each of 41 field-coordinate equations it formed the equation and its products by all source-bit monomials of degree one or two. A row-span equality to constant one excludes the entire 4×1,024 code block. The [proof map](PROOF_MAP.md) gives the faithful Lean structural implication; the independent Sage audit checks the exact finite-field polynomial and each selected row XOR.
