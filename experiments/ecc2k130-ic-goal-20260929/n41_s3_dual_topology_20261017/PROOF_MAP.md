The pinned Lean 4.34.1 module [`DualTree.lean`](DualTree.lean) builds, and `#print axioms` reports only `propext`. This is the central structural implication for the extra topology.

Independent Sage group addition verifies both tree associations on the archived public relation. Formal curve-to-S3 and Boolean-circuit semantics remain open.
- **Exceptional reciprocal chart.** Every non-final node must have nonzero `x` and be nonidentity for `1/x` to exist. [`chart_audit_sage.py`](chart_audit_sage.py) enumerates the 24,864 valid state pairs for each of three first-level cross pairings, then uses an exact point-key join for the four-source node. The saved result finds no identity or binary-curve two-torsion point in either set. The target itself has nonzero `x`. This is an exhaustive property of the frozen N41 source domains with the distinct-column rule; its N131 analogue requires a new source-bound check.
