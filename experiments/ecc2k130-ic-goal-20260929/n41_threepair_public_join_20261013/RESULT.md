# Exact N41 public three-pair source census and PMULL join

**The frozen W8 rotation-zero source has no eligible three-pair decomposition of the N41 public point.** An output-first group join covered all 64 first-state buckets, independently audited **921,849,984** eligible ordered two-state probes, and found zero matching source x-coordinates. A constructed-target control recovered its six-column witness and passed independent checked-Sage replay. The same experiment replaced bit-serial `GF(2^41)` multiplication with ARM PMULL plus two polynomial folds; on the identical first public bucket the archived calibration reduced join time from **86.970 s to 15.997 s** with identical probe and match counts. That local timing ratio is exploratory because the host was not isolated.

## Exact input and search

The curve is `EC1N41Ckb1h7d5e80d3c4d0`, `y²+xy=x³+1` over `GF(2)[t]/(t^41+t³+1)`, with subgroup order `549756390943` and cofactor four. The fixed public point is `(920359962848,755404565011)`. The [source table](../n131_w18_allseed_fourpair_20261012/n41_diagonal/pairs.tsv) has SHA-256 `df367421657bf29d7c47a9bd62b26c6424993e81b98d4d1f70cb7e05f0d8b22a`: 30,952 signed unordered pair states derived from 125 rational W8 masks. Each state records a point and two folded columns. This component has `candidate_id: null` because relation collection, final matrix solving, and target-log recovery are not specified by it.

The [baseline join](join3.cpp) indexes the complete source by point x-coordinate. For each first state `P_i` in a bucket and each second state `P_j` with four distinct folded columns, it computes `Q-P_i-P_j` using one batch inversion per first state, then looks up the residual point. It compares both coordinates, checks two further distinct columns, and replays any hit with generic group addition. The first-state buckets are `i mod 64`, ordered by the frozen SHA-256 rule in [public_protocol.json](public_protocol.json). The [Lean theorem](JoinCorrectness.lean) proves that residual equality is equivalent to the three-point group sum under explicit commutative group laws. The batch-inversion and field-kernel implementations are additionally checked by differential code paths; see [PROOF_MAP.md](PROOF_MAP.md).

The [PMULL source](join3_fast.cpp), generated by [make_fast.py](make_fast.py) from hash-pinned archived arithmetic and the baseline join, computes a carryless 41-by-41 product and reduces it modulo `t^41+t³+1`. It checks 100,000 deterministic products against the bit-serial multiplier before each run. The control's exact group sum was reconstructed from the underlying W8 geometry by [checked Sage](control_replay_result.json). The [cofactor audit](coset_result.json) found 15,552 source states in the subgroup class and 15,400 in the other order-two class; the public point is in the subgroup class. Thus cofactor class alone does not exclude a three-pair relation.

## Consequence and next gate

This closes the **rotation-zero three-pair source on this public point**. It does not turn a timed-out reciprocal SAT formula into a solver `UNSAT` certificate: formula equivalence at exceptional reciprocal charts is a separate obligation, and any model must still pass full group replay. The N131 W18 three-pair upper mean was already only `6.025×10⁻⁸` labeled tuples per uniform subgroup target in the [all-seed source analysis](../n131_w18_allseed_fourpair_20261012/RESULT.md). The next target-conditioned solver gate therefore needs four pair blocks, the known N41 eight-column public control, and early rejection of joint partial-sum families before mask expansion. Freeze the rejection predicate, measure its unpinned ordinary-query rejection and complete cost on that N41 source, and project the same implicit construction to one N131 worker under 600 s and 4 GiB before another public query.

The source also illustrates why ordered tuple counts misstate independent coverage. An accepted three-pair relation uses six distinct W8 masks, so its sum belongs to at most `binom(125,6)·2^6 = 300,200,032,000` signed six-mask values, before source-edge and folded-column restrictions. Many ordered pair triples name the same signed sum. This is a combinatorial **upper bound on represented sums**, not a probability estimate for the fixed public point. Its written argument and formalization boundary are in [PROOF_MAP.md](PROOF_MAP.md).
