# Batched x-only terminal-pair filter

The target-conditioned fifth-pair test now shares field inversions across a whole four-slot box and delays residual y-coordinate construction until the product-subspace test finds a code. The batched implementation exactly matched the direct implementation on every one of 2,304 residuals in each of the frozen N41 and N131 panels. The constructed relations retained fifth codes `63` and `29`, with ten distinct folded columns; the eight public boxes in each panel recorded zero verified relations. The [terminal verifier](terminal_result.json) reports `PASS_BATCH_OUTPUT_FIFTH_FINITE_PANEL_AUDIT`. This is a component of point-decomposition search, so `candidate_id: null`.

For each box, the worker precomputes 16 two-slot sums on each side. It forms `L=T−(P₀+P₁)` and `R=−(P₂+P₃)`. For each of the 256 pairs `(L,R)`, the binary-curve addition slope uses denominator `x(L)+x(R)`. A single batch inversion supplies the nonzero denominators; the exceptional equal-x cases use the complete group law. From each slope, the worker computes only `x(L+R)`. A second batch inversion supplies the nonzero unrotated output x coordinates. The [previous exact inverse](../output_first_fifth_20261019/RESULT.md) then tests `H x+C/x` for membership in the 10- or 32-dimensional source-product subspace. Only a subspace hit reconstructs the full residual point and all four signed pair outputs before checking the exact relation.

The direct and batch wall times are separate ordinary-host runs that include panel loading, partial-sum preparation, all nine boxes, and hit checking. They are exploratory component diagnostics, not an isolated one-target IC comparison. The batch-only run's raw peak RSS was 26,820,608 B on N41 and 22,052,864 B on N131, below the frozen 4 GiB cap. The parity runs, which also execute the direct path for every residual, took 0.971 and 5.184 seconds; those times are not the batch-only column above. Every run used one process and completed below its 120 s N41 or 600 s N131 cap.

The per-residual parity script computes the complete direct group residual and source-product decision independently of its batched x-only path and compares every status and x coordinate. The frozen prior [Sage audit](../output_first_fifth_20261019/terminal_result.json) separately reconstructs all 2,304 residuals per field from the exact binary curve. The terminal verifier checks source hashes, frozen caps, status vectors, recovered codes, distinct columns, and the Lean output. The initial `/private/tmp` experiment and its protocols are retained under `scratch/`; the root records are the canonical repository rerun.

This improves residual-query throughput after four source states are selected. The unresolved step is a target-coupled test that rejects many four-code families *before* building their 256 residuals. The next test should measure exact family rejection per construction operation on an unpinned N41 ordinary relation and a zero-relation control, then project its work and memory to the frozen N131 public-point cap.
