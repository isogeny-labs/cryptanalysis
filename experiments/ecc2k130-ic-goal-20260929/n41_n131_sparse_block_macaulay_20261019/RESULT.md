# Sparse streamed degree-six block reduction on N41 and N131

A sparse, streamed Boolean Macaulay reducer reproduced all five N41 empty-block exclusions and retained the N41 public-relation block, while using at most 34,045,952 B sampled combined RSS per N41 cell. Its N131 transfer kept the complete degree-six monomial index within a 4 GiB worker: the constructed-positive block reached 17,000 independent pivots in 590.039 s with 1,107,935,232 B sampled combined peak RSS. This replaces the preceding 15.23 GiB literal rectangular-matrix estimate with measured sparse storage for a bounded prefix. The N131 run ended at `WALL_CAP`; the frozen public-target block was gated and its certificate status is `UNKNOWN_search_cap`. This remains a point-decomposition component with `candidate_id: null`.

The N41 control uses curve `EC1N41Ckb1h7d5e80d3c4d0`, `GF(2)[u]/(u^41+u^3+1)`, `y²+xy=x³+1`, subgroup order `549756390943`, and cofactor four. The N131 transfer uses `EC1N131Ckb1heb5f1998f20b`, `GF(2)[u]/(u^131+u^13+u²+u+1)`, and the same curve model. The frozen W11 and W33 source encodings, target rows, and exact 13-term two-product eliminant are identified by the hashed [preparation protocol](prepare_protocol.json). N41 cells have two free left bits and ten free right bits; N131 cells have two free left bits and 32 free right bits. The 131-bit positive target has a known code-pair witness `(3,16722)` from the [preceding N131 result](../n131_w33_block_macaulay_20261019/RESULT.md). The public row uses the frozen raw point from that result.

For every field-coordinate equation, the reducer streams its product by each Boolean monomial of degree zero, one, or two. It enumerates columns of total degree at most six, reduces rows over `GF(2)` with sorted sparse supports, and retains row-combination IDs. A constant-one combination is emitted as a replayable exclusion certificate. There are 2,510 columns and 3,239 requested rows for N41, and 1,676,116 columns and 78,076 requested rows for N131. Source and binary hashes, compiler, and build command are in [build_result.json](build_result.json). The complete equation files were independently reconstructed with the checked repository Sage launcher and matched coefficient by coefficient in [audit_result.json](audit_result.json): 24,576 N41 code values are covered by the prior control audit, while this audit checks all eight sparse input expansions.

For the capped N131 cell, 17,000 is its last emitted progress checkpoint, not an assertion that the worker executed exactly that many rows. Its row-combination support reached 7,109 IDs and its largest intermediate sparse row reached 56,535 monomials. Those are producer diagnostics, not certificates. The positive-first gate required a terminal `UNRESOLVED_AT_DEGREE6` result before starting the public block; the cap therefore prevented a public-target query under this protocol. Each measured cell had one worker and a 4 GiB RSS cap. The N41 cell cap was 120 s; N131 was 590 s, leaving the 600 s objective envelope for input preparation and checks. These are ordinary-host algorithmic diagnostics, not isolated online IC or same-point rho measurements.

`python3 verify_n41.py` replayed each of the five certificates to the singleton constant polynomial and checked every frozen N41 receipt and source hash. `python3 verify_n131.py` checked the N131 protocol, independent Sage input audit, positive-first gate, timeout receipt, hashes, and the absence of a terminal certificate claim in the capped log. Both passed; their stdout and stderr are retained. The [proof map](PROOF_MAP.md) connects certificate soundness to the checked Lean theorem and specifies the finite bridges.

The next iteration should reduce the cost per N131 row before another full block attempt. A concrete first comparison is a packed GF(2) row representation with delayed combination tracking, paired on the exact six N41 cells and the frozen N131 positive cell under the same worker, memory, and wall caps. It should preserve independently replayable certificates and report all failures. If the positive completes, run the frozen public cell, then attempt the original ordinary factor-base relation gate.
