# Adjacent-Frobenius source map and public N41 relation

**Sharing an adjacent Frobenius pair produced an independently replayed,
rank-increasing relation on the frozen N41 public point in 11.491 s of
ordinary-host runner wall time.** The row has 18 nonzero folded columns;
insertion raises the rank of the prior six-, nine-, and ten-pair rows from
3 to 4. The exact source map then covered all 66,382 raw W18 N131 pair
roots. An independent field implementation checked 132,764 map equations,
and checked Sage group addition replayed 512 sampled point-sign cases.

The algorithmic block starts from one source pair point (P) and uses
both (P+τ P) and (P-τ P), where τ squares each coordinate.
For the curve (y^2+xy=x^3+1) and (x(P)\notin\{0,1\}), define
(f(x)=x+1/x). Then

\[
x(P+τ P)=f(x(P)),\qquad x(P-τ P)=f(f(x(P))).
\]

For (a=1/x(P)), the output reciprocals are
(b=a/(1+a^2)) and (c=b/(1+b^2)). Thus a repeated adjacent
source occurrence can be generated by two field maps on one root,
with the output sign decided during lifting. The [proof map](PROOF_MAP.md)
gives the cleared polynomial identity, exceptional cases, and formalization
status.

## N131 W18 source-map gate

The N131 curve is `EC1N131Ckb1heb5f1998f20b` over
`GF(2)[t]/(t^131+t^13+t^2+t+1)`. The source is the frozen W18
seed-212 canonical root table with 33,191 valid codes and 66,382 raw
reciprocal roots. The [N131 protocol](n131_protocol.json) fixes that
table, its preparation receipt, the N41 audit, mapping script and checked
[Sage runtime](n131_sage_runtime_info.json) before execution.

Two batch inversions produced the [mapped output](adjacent_roots.bin),
containing a plus and minus reciprocal for every raw root. Source parse,
two batch maps, serialization, and 512 Sage group checks took
0.070535, 12.460776, 12.765531, and 5.803109 seconds, respectively,
for 31.099951 seconds in the [Sage record](n131_result.json). Peak
self RSS was 342,491,136 B. A separately implemented GF(2^131)
multiplication routine checked `b(1+a^2)=a` and `c(1+b^2)=b`
for every root in [132,764 field equations](n131_verify_result.json).
The checked output has SHA-256
`4d2a5dad21c64a2299625bde8d5d08fc3a746e548a58c83f9a27301e8a98ac77`.
