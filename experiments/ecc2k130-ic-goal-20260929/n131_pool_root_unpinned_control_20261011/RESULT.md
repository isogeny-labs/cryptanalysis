# Terminal-pool root inversion retains two ordinary N41 relations

The fixed-terminal W18 product eliminant retained **both independently replayed ordinary N41 relations** when their first and terminal pairs were considered as a four-point block. For each relation, scanning all eight terminal edges and every admissible first-pair source product returned exactly its recorded edge and product. On the N131 constructed block, the same eight-edge test returned exactly `(terminal code 10, first product 3328, source code 4)`. A separate bit-field evaluator checked all **265,509 N131 terminal-edge/product pairings** and agreed with the checked-Sage root extraction. The result is a source-aware inverse for a *specified* four-point output, including terminal-edge selection.

## Frozen inputs and method

The [producer protocol](protocol.json) hashes its executable, the checked [Sage runtime](sage_runtime_info.json), the independently replayed N41 ordinary rows and field geometry, the N41 public-point fixture and query receipt, and the prior N131 fixed-terminal result, pool, source circuit, and W18 support. It was frozen before `run.py` executed. The [audit protocol](audit_protocol.json) separately freezes `audit.py`, the producer result, and the N131 source inputs before its bit-field scan. Both use one worker, a 600-second parent cap, and a 4 GiB RSS cap; the audit also caps each terminal-edge scan at 120 seconds. Candidate ID is null because the measured object is a decomposition component.

N41 uses GF(2)[t]/(t^41+t³+1), `y²+xy=x³+1`, curve `EC1N41Ckb1h7d5e80d3c4d0`, W8 seed 184, and the previously frozen seven-pair terminal-32 public workload. The supplied transported public point is `(920359962848, 755404565011)` and its selected raw preimage is `(344545435656, 924092594889)`. The two source rows have novel rank two and sum to that raw preimage; their existing independent Sage replay is bound into this run. The first and terminal slots are both at rotation zero. The terminal law covers all four signs of each of the first eight source edges; the product polynomial depends on the edge, so the scan covers eight distinct terminal products. Each edge leaves 34 admissible first-pair products after its folded columns are excluded. The producer independently reconstructs each seven-pair raw sum before computing the four-point output `z`.

N131 uses GF(2)[t]/(t^131+t^13+t²+t+1), the same curve equation, curve `EC1N131Ckb1heb5f1998f20b`, W18 seed 212, first-pair rotation zero, and terminal rotation 128. Its output `z` is the constructed four-point block checked in the prior fixed-terminal experiment. The eight terminal edges leave 33,188–33,190 first-pair products each. The two-quadratic half-trace elimination produces a degree-four polynomial `H_{q,z}(p)` for each terminal product `q` and fixed output `z`; roots are intersected with the exact source after folded-column exclusions. Each hit still requires point-sign and full-group verification. The independent audit evaluates all eight polynomials at every admissible source product with separate bit-field polynomial arithmetic.
