**The frozen N41 two-pair output sample spans every degree-at-most-two Boolean function on the subgroup's trace-zero (x)-coordinate hyperplane.** The independently replayed rank is **821 of 821** after accounting for the exact trace constraint. Consequently, any degree-at-most-two (x)-only polynomial that accepts every legitimate two-pair output also accepts every subgroup residual `Q′−P₁−P₂−P₃`; it cannot reject a target-conditioned family in this five-pair layout. This is an exact obstruction for this filter class, not an extrapolation from timing.

## Why the rank exhausts the filter class

The checked Sage trace basis is `(1,0,…,0)`, so `Tr(x)` equals the constant coefficient bit `x₀` in this polynomial representation. On `y²+xy=x³+1`, the doubling formula gives `x(2P)=λ²+λ`; absolute trace is additive and `Tr(λ²)=Tr(λ)`, hence `Tr(x(2P))=0`. Doubling is bijective on the odd-order subgroup, so **every subgroup point has `x₀=0`**. In particular, both legitimate two-pair outputs and every target-dependent residual `Q′−P₁−P₂−P₃` lie in this hyperplane.

On `x₀=0`, degree-at-most-two Boolean polynomials reduce uniquely to the `1+40+binom(40,2)=821` monomials in the remaining 40 bits. The Sage-replayed 821 feature rows have rank 821. Any polynomial in this class that vanishes on all legitimate two-pair outputs vanishes on those rows; full rank makes its restriction to the entire trace-zero hyperplane identically zero. Thus it cannot reject any subgroup residual, irrespective of the particular public target.
