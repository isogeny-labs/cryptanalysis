# Sparse quadratic signature proof map

The finite result is an exact census of truth signatures on named N41 partial families. For each family the native program evaluates the constant, the 40 nontrace coordinate functions, and all 780 squarefree quadratic coordinate products on every distinct reciprocal in that family. A monomial identity with one term is a zero signature; two terms are duplicate signatures; three terms give a pair XOR equal to one signature; four terms give two pair XORs with disjoint indices. The native worker searches these cases exactly using 128-bit signatures. The independent Python audit rebuilds the witness-centered left and right families and sample zero's left and right families from raw archived curve points and repeats the signature search using arbitrary-precision integers.

`SignatureCollision.pair_collision_implies_four_term_zero` proves the pointwise implication from a pair-signature collision to a four-term Boolean identity for arbitrary sample type and Boolean functions. `SignatureCollision.zero_coordinate_product` proves that a zero coordinate makes every product containing it zero. Both declarations compile under the pinned `leanprover/lean4:v4.34.1` toolchain; `lean_check.log` retains `#print axioms`, reporting only standard `propext` for the collision theorem and no axioms for the zero-coordinate theorem. The first two failed Lean attempts and their errors remain in `lean_check_attempt1.log` and `lean_check_attempt2.log`.

The Lean module does not formalize GF(2^41), the curve, the archived point table, or the complete 16-family nonexistence certificate. The native frozen census supplies the full finite check, and the independent Python audit checks four selected families. Full kernel formalization of the finite certificate would need a bitvector field model and a checked import of the 16 family's reciprocal lists; this bridge is open. The field-basis trace computation found `Tr(1)=1` and `Tr(t^i)=0` for `1≤i≤40`; the native version-two worker additionally checks both trace zero and bit zero for every evaluated reciprocal.
