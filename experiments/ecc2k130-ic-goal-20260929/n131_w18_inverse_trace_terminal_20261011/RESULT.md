# Exact inverse-trace source gates shrink the N131 W18 terminal circuit

Replacing the eight 13,093-node source-support BDDs with two inverse-and-trace witnesses per pair preserves the exact 33,191-code canonical W18 source domain and reduces the public-query circuit to **189,687 variables, 129,069 AND gates, and 10,830,220 XCNF bytes**. The [source gate census](gate_equivalence.json) proves that every canonical code with two rational endpoints is in the previous BDD set and that none of those pairs shares a folded column. The [constructed control](control_result.json) satisfies every clause and native-XOR row with explicit inverses for both endpoints. This is an exact encoding improvement on the challenge field.

The field is `GF(2)[t]/(t^131+t^13+t²+t+1)`, the curve is `y²+xy=x³+1`, and the subgroup order is `680564733841876926932320129493409985129` (curve ID `EC1N131Ckb1heb5f1998f20b`). The frozen public workload is `cc09e7eb202a`, raw preimage zero. Eight free W18 fixed-seed pairs use rotations `0,16,...,112`; the ninth signed terminal pair is pool state zero at rotation 128. Its selected source masks are `10,222` with signs `0,0`, fixed before the public query. The terminal subtraction and seven-link halftrace-cubic S3 chain are identical to the [fixed-terminal baseline](../n131_w18_fixed_terminal_20261011/RESULT.md). The exact source-support mean upper ceiling remains 35.4022876484 labeled tuples for a uniform raw point; it is a combinatorial count, separate from measured solver yield.

For a canonical endpoint field element `w`, the replacement introduces `v` with `w·v=1` and `Tr(v)=0`. It applies this predicate separately to `w` and `w+seed`. The archived W18 support had already been checked against the same inverse-trace rationality predicate for all masks by the [native source audit](../n131_w16_w18_sixpair_width_gate_20261010/native_audit_result.json); the new [census](gate_equivalence.json) checks all `2^17` canonical pair codes against the archived folded-column table. No pair-column inequality is needed for this seed because the 33,191 both-rational codes have zero equal-column cases. The [frozen protocol](protocol.json) pins the support, code, solver, target, terminal state, resource cap, and prior independent Sage residual checks by hash.
