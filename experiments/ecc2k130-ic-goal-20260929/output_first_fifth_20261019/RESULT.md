# Output-first recovery of the fifth W33 source code

An exact target-conditioned inversion recovers the fifth source code from each four-slot residual using one field inversion and a binary linear lookup. This applies the [earlier exact two-pair source-product inverse](../n41_w11_exact_two_pair_oracle_20261018/RESULT.md) to the N131 W33 five-pair terminal slot and independently replays every frozen residual. For the fixed-seed reciprocal pair construction, write the unrotated pair-output coordinate as `x`, the source product as `p=a(a+s)`, and the fixed coefficients as `H,C`. The pair-output law is `H x² + p x + C = 0`; with `x≠0`, it gives `p=H x+C/x`. Since `a↦a(a+s)` is additive in characteristic two, a precomputed product-basis elimination either recovers one source code or rejects the residual. Source eligibility, signed pair reconstruction, ten distinct folded columns, and the exact group relation are checked after a code is recovered. The source-product basis has rank 10 in N41 W11 and rank 32 in N131 W33.
