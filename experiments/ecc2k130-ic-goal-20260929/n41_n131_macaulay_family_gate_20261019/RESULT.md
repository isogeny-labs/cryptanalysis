# Degree-three family certificates and matched N131 root filter

A degree-three Boolean Macaulay row-span certificate rejects an entire right-product code family for one fixed left product. The full frozen N41 panel contained 7,025 first-code families across 25 target-conditioned residuals: the filter rejected 7,024, retained the family containing the known relation, and an independent checked-Sage audit replayed every rejection certificate. On the frozen N131 W29 pilot, it rejected 11 of 12 families and retained the planted positive family; the audit replayed all 11 certificates and the positive group witness. A matched N131 comparison found that the **already implemented** quartic/subspace-polynomial GCD filter made the same 12 decisions with a 57.7 ms median specialization-plus-GCD stage, versus 295.5 ms for shared-core Macaulay and 832.2 ms for direct Macaulay linearization. The GCD implementation is the faster baseline for further work; the Macaulay path supplies independent contradiction certificates and a reusable normalized quadratic core.

## Exact inputs and algebra

The N41 field is `GF(2)[u]/(u^41+u^3+1)` on `y²+xy=x³+1`, curve ID `EC1N41Ckb1h7d5e80d3c4d0`. The N131 field is `GF(2)[u]/(u^131+u^13+u²+u+1)` on the same model, curve ID `EC1N131Ckb1heb5f1998f20b`. The 13-term two-product eliminant `H(p,q)` and its fixed-slot scope are derived in the [prior eliminant result](../n41_w9_two_product_eliminant_20261017/RESULT.md); the N131 coefficients and two target rows are pinned by [coefficients.json](../n131_w33_freecode_resultant_20261018/coefficients.json). The W29 restriction uses seed mask `898618` and 28 free code bits. The N131 pilot's first codes were frozen as `3,18,19,22,29,16722`, tested against both the constructed positive target and the frozen public point. The positive code pair is `(3,16722)`.

For a fixed left product `p`, write `H_p(q)=A₀+A₁q+A₂q²+A₃q³+A₄q⁴`. The right product `q(b)=Σ bᵢvᵢ` is linear in Boolean source-code bits. Squaring and fourth powering are also binary-linear, while `q³=q·q²` has squarefree degree two after `bᵢ²=bᵢ`. Thus each field-coordinate equation of `H_p(q(b))=0` is a Boolean quadratic. The filter forms these equations and their products by each bit, expands into degree-at-most-three squarefree monomials, and checks whether their binary row span contains the constant polynomial `1`.

**Soundness proof.** At any right code solving the eliminant, every original coordinate equation evaluates to zero. Every bit-multiplied row evaluates to zero as well. If an XOR of these rows is identically `1` in the Boolean quotient, evaluating it at that code gives `0=1`. Therefore a constant-one row-span certificate excludes all `2^f` right-code assignments, including every valid factor-base code. The converse is not required: an unresolved family may have no valid right code. The producer saves selected source-row descriptors `[field_bit, multiplier_bit]`, with `-1` denoting an unmultiplied row. Auditors regenerate the equations from frozen field coefficients and verify that the selected row XOR is exactly the constant polynomial.

Dividing by nonzero `A₃(p)` makes the quadratic coefficient of `q(b)³` independent of `p` and the target. The 2,966-dimensional high-degree row span and its 702-dimensional nullspace were prepared once; a 407-column low-degree solve then reproduced all 12 direct N131 rank and rejection decisions. This normalization is an implementation optimization, not a changed relation criterion.

The N131 public row tests **six selected first codes**, not the complete W29 domain. The positive row is a constructed correctness control. These are stage diagnostics on an ordinary shared host, so their ratios do not establish single-target online performance. Caps were checked by the processes rather than enforced by an OS isolation service. All local Sage runs used the checked repository launcher, with [runtime receipt](sage_runtime_info.json) saved before the measured jobs. The stage artifacts retain `candidate_id: null` because this is a fixed-slot component rather than a complete IC pipeline.

The 65,536-mask W29 source sample contained 16,677 valid pairs. Applying that sample rate to `2^28` codes gives a **projection** of 68,308,992 eligible left codes. At the measured 57.7 ms GCD stage median, a serial pass over that projected count would take about 45.6 days, even with the other three pair slots fixed. The 600 s gate would need about 113,848 such specializations per second, roughly 6,567 times this pilot throughput before accounting for outer-slot search. This identifies the next algorithmic step: a constraint that rejects blocks of left-product codes or jointly binds more pair slots, rather than another serial left-code sweep. The frozen N131 public-point ordinary-relation gate remains open.
