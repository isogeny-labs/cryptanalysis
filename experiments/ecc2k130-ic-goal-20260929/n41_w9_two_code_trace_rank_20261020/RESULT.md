# Full rank of two-code affine trace features on the N41 W9 source

The exact two-pair source on the frozen N41 public relation admits **no
nonzero universal code-degree-at-most-two predicate affine in its
reciprocal partial-sum coordinate** when both code orientations are
included. The 5,754 feature columns reach full binary rank after all
2,482 eligible `left < right` families and seven reversed families.
The independent low-pivot replay reproduced this result. Under the
symmetry-normalized `left < right` domain, rank is 5,712/5,754; its
42-dimensional nullspace consists exactly of the source-only top-bit
ordering relation multiplied by the 42 output features. This narrows
the next target-conditioned gate to higher code degree, nonlinear
partial-sum dependence, or a constraint coupling additional families.

## Exact source and features

The field is `GF(2)[u]/(u^41+u³+1)` and the curve is
`y²+xy=x³+1`, ID `EC1N41Ckb1h7d5e80d3c4d0`. The aligned W9 source
uses seed 56 and two equal-rotation pair slots. Each slot has 71
source-valid eight-bit codes and four signed states per code. The
frozen family law includes exactly 2,482 ordered `left < right` code
pairs with four distinct folded columns. A seeded order places the
verified public-relation family `(93,228)` first. The archived five-pair
state IDs `(105,244,66,47,111)` sum to Frobenius orientation 6 of the
public raw point; the exporter checked this equality before evaluating
any family.

Each family has 16 signed state assignments and exactly eight distinct
reciprocal x coordinates `z` of its two-pair sum. The feature row is
`m(left,right) · (1,z₀,…,z₄₀)` for each of the 137 Boolean code
monomials of total degree at most two. Thus there are `137×42=5,754`
binary features. Every proposed predicate in this class is a linear
functional on those features.

The code-only monomial nullspace under `left < right` is generated by
`left_bit7 · (1+right_bit7)`. It vanishes because an eight-bit number
with top bit one cannot be less than an eight-bit number with top bit
zero. Its 42 products with the constant and output bits account for
the complete ordered-domain rank deficit. The independent verifier
checked the code-only rank, every ordering implication, all feature
rows and the first full-rank reversed family. [PROOF_MAP.md](PROOF_MAP.md)
maps the structural implication and ordering fact to checked Lean 4
declarations.

## Receipts and next gate

`families.json` and `export_protocol.json` were frozen before output
generation. Separate protocols bind the rank producer, orientation
extension, arithmetic audit, and independent verifier to exact source
hashes and worker/wall limits. The first verifier accidentally rebuilt
the original orientation in its reversed branch; its assertion failure,
stdout, stderr, script hash and protocol hash are retained. The
separately frozen retry corrected that one code-label operation and
passed the independent low-pivot replay. All completed runs used one
worker and stayed below their declared wall caps. The Sage runtime
receipt was saved before the arithmetic jobs; the exact output audit
used the checked repository launcher. RSS figures are observations,
not a host-isolation or 4-GiB watchdog receipt. `candidate_id: null`
because this is an exact point-decomposition filter screen, not a
complete IC candidate or online DLP comparison.

The result rules out this low-degree, two-family affine trace gate on
the exact N41 source. The next constructive test should couple at
least a third free source family to the public point through a
nonlinear residual equation, while preserving the unpinned N41
relation and measuring whole-family rejection before source-state
enumeration. A source-bound N131 one-worker/600-second/4-GiB public
relation attempt requires that gate first.
