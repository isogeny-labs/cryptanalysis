# Interleaved Macaulay certificate excludes a public N131 source block

An interleaved degree-six Boolean Macaulay reduction produced and independently replayed a **4,414-row constant-one certificate** for the frozen N131 public point. It excludes every one of the **4 × 2³² = 17,179,869,184** source-code pairs with left code `0..3` and arbitrary 32-bit right code from satisfying the exact target-conditioned two-product resultant. The producer reached the certificate after **13,071 of 78,076** possible equation-multiple rows in **204.902 s** parent wall with **346,669,056 B** sampled combined peak RSS, one worker, and a frozen 590 s/4 GiB cap. The independent verifier XORed all selected multiples and obtained exactly the constant polynomial `{0}`. This is a full decision for this one public block, with `candidate_id: null` for the still-incomplete IC pipeline.

The field is `GF(2)[u]/(u^131+u^13+u²+u+1)` and the curve is `y²+xy=x³+1`, identified by `EC1N131Ckb1heb5f1998f20b`. The frozen public raw point is `(877610862732227974378969808549299291499, 2063336771837286479337213121437715536874)`. The W33 source uses seed mask `898618`, 32 free canonical bits, and pair rotations `(0,18)`. The two-product eliminant is the exact 13-term bidegree `(4,4)` polynomial exported in the [N131 source archive](../n131_w33_freecode_resultant_20261018/RESULT.md). This run uses the byte-identical coordinate ANFs independently reconstructed from checked Sage arithmetic in the [sparse input audit](../n41_n131_sparse_block_macaulay_20261019/RESULT.md). The public query protocol hashes the executable, row-order source, exact field-coordinate inputs, audit, N41 gate, witness gate, and checked runtime.

The row family is unchanged: multiply each of 131 coordinate equations by every Boolean monomial of degree zero, one, or two in the 34 source bits. The implementation now processes all 131 field coordinates for one multiplier before moving to the next multiplier. Previously it processed all 596 multipliers for one coordinate before moving to the next. The column order and exact GF(2) elimination are unchanged, and each emitted certificate identifies original coordinate and multiplier pairs. Interleaving brings independent coordinates into the span early enough to expose a constant-one identity at the 13,071st processed row. The source [implementation](interleaved_block.cpp), [build record](build_result.json), and [public protocol](query_protocol_n131_public.json) fix this schedule.

Before the N131 public run, the same executable passed all six frozen N41 controls. Five empty blocks yielded independently replayed exclusions; the block containing the known public-relation component `(253,63)` remained satisfiable. Direct evaluation of the N131 constructed-positive witness `(left=3,right=16722)` satisfied all 131 coordinate equations, and the earlier checked-Sage slice audit independently located that root. The positive witness was checked directly instead of requiring a complete row-span computation on a known satisfiable block.

This block exclusion changes the next search step. The two-pair W33 family contains at most `2^64` complete code pairs across **all** left blocks, so enumerating more blocks of the same family is a poor route to an ordinary relation in the roughly 130-bit target group. The useful next test is a target-conditioned multi-pair join: form frozen public residuals from a bounded, independently verified suffix of additional pair sums, then apply the interleaved block certificate to those residuals while charging suffix construction, every rejected block, and every candidate root. A certificate rejects a complete block; it does not itself produce a relation. The active objective still requires an ordinary verified relation, useful rank and factor-base logs, a verified one-target DLP, and a matched online rho comparison. The present run establishes an exact N131 public-block decision within the stated worker envelope and gives a concrete row-order improvement for that component.
