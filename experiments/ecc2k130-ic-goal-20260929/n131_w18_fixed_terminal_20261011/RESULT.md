# Fixing one terminal pair makes the N131 residual a field constant

Fixing one signed W18 terminal pair before the public query removes the 32-way residual selector from the target-conditioned eight-pair circuit. On the exact ECC2K-130 field, the ordinary formula has **441,147 variables and 189,608 AND gates**, reducing the [32-state terminal-fiber formula](../n131_w18_terminal_fiber_20261011/RESULT.md) by **9,801 variables and 5,686 AND gates**. The constructed challenge-field witness satisfies every clause and native-XOR row. The ordinary public-point query reached the frozen **600-second total target-dependent wall cap** with `BOUNDED_UNKNOWN` and a sampled solver CPU total of only **36.554 seconds**; the result is a censored search, not a fixed-target source count.

The exact field is `GF(2)[t]/(t^131+t^13+t²+t+1)` on `y²+xy=x³+1`, with curve ID `EC1N131Ckb1heb5f1998f20b`, subgroup order `680564733841876926932320129493409985129`, and cofactor four. The public workload remains `cc09e7eb202a`, raw preimage index zero, paired to the same point in the earlier nine-pair and 32-state runs. Eight free pair slots use W18, source-mask XOR seed 212, and Frobenius rotations `0,16,...,112`; all their masks, point signs, pair outputs, and intermediate coordinates remain unpinned. The ninth pair is [state zero of the previously frozen pool](../n131_w18_terminal_fiber_20261011/pool.json): masks `10,222`, source signs `0,0`, rotation 128. It was selected before this ordinary query and is exact curve data, not a witness supplied by the public point.

For the supplied raw target `U` and fixed terminal point `P₈`, the online preparer computes `R=U−P₈` and feeds `1/x(R)` as the final constant of a seven-link halftrace-cubic S3 chain. The [source-count protocol](protocol.json) removes all pair edges incident to the terminal state's two folded columns and counts the remaining eight-edge matchings with ordered signed assignments. Its **uniform raw-point mean upper ceiling is 35.4022876** labeled tuples. This is a source-support ceiling; it neither guarantees a decomposition for the fixed point nor measures ordinary relation yield. The terminal point and both control/public residuals were independently checked by the prior [Sage fiber replay](../n131_w18_terminal_fiber_20261011/sage_audit_result.json), whose hashes are frozen into this run.
