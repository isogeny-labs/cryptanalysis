# Target recovery from the noncyclic p941 X011 relation lattice

The certified p941 relation lattice yields **coordinates for all 112 ordered fiber points** in the curve group of order 900. Reducing the 180-by-60 generator-pair grid against the saved row-Hermite basis gives exactly 900 cosets; each fiber basis vector maps to one of them. Independent curve arithmetic verifies every reconstructed pair. The order-180 subgroup generated by `(32,685)` contains 23 prepared fiber points. For the frozen public point `(283,221)` in that subgroup, one addition reaches the prepared set and returns scalar 170 modulo 180. Two same-point Pollard rho runs return the same scalar.

This tests relation-lattice log preparation in a noncyclic ambient group. The one-target DLP is deliberately defined in the order-180 cyclic subgroup, with the exact generator and public point fixed in `protocol.json`; the pair coordinates of the remaining fiber points are preparation evidence. The target seed and point selection rule were frozen before execution. `freeze.py` writes a public point and a separate known-scalar audit fixture. `run.py` reads the public point only. Sage independently verifies the 900-point pair span, all 112 fiber coordinates, the 23-point subgroup intersection, and the four run answers.
