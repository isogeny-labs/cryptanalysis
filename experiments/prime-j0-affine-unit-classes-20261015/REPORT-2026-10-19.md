# Deferred unit-class affine tree: report

## Question and scope

Can the signed radix-14 lookup points be grouped by order-three x-rotation class, batch-added within each class, and rotated only after each class has been summed? This trades fewer per-leaf x-constant multiplications for three class lanes and a fifth inversion layer. `UnitClasses.three_class_delayed` proves the abstract group identity under explicit zero-preserving/additive endomorphism hypotheses; the native replay tests the concrete implementation. The formal result does not model the native Rust arithmetic bridge.

## Retained validation and exploratory result

The native release test checks 128 frozen scalar outputs against the parent affine-layer outputs, fixture points and an independent binary multiplier, including the identity case. All captured benchmark outputs shown here report `verified=1`, matching fixture hash `7f4672b7b676969fe40056d0f14c6ecf45ad36109870cdf3466ebafd9e7b22d8`, 12,288 outputs, and 26,035,988 retained bytes.

The sequential A/B/A sizing screen measured:

The candidate/mean-parent ratio is **1.106×** in this single exploratory sequence. It has no pinned-runner A/A receipts or uncertainty estimate, so it is not a qualified performance result. The separate retained `unit-class-screen.stdout` diagnostic measured the candidate at 57.438771 ms; it is preserved, but is not pooled with the A/B/A sequence. The available screen does not support promoting this layout as a speed improvement. The README's build/test archive records the source, logs, failed or diagnostic attempts, and hashes.

## Proof, implementation and graph boundary

The group-level theorem requires `tau(0)=0` and additivity. The parent `AffineLayer.layers_preserve_sum` result proves the tree reduction under its explicit affine pair-addition hypothesis. `check_lean.sh` pins Lean 4.34.1 and the captured check log records the theorem's axioms. The native test supplies a separate implementation check; a Lean refinement of that concrete bridge remains open.

The figures are generated from retained raw stdout by `visuals.py`; no analyzed or frozen result file is rewritten. The source search was checked against the canonical scalar-pipeline graph: it introduces no qualified pipeline improvement and does not alter the selected pipeline or its costs, so those canonical graph sources remain current. The local A/B/A bars are a report of an exploratory diagnostic, not a promotion to the canonical graph.

## Decision and next step

This layout was not selected for a qualified speed panel. Preserve its correctness screen and negative timing lead; do not route work to it based on this uncalibrated comparison. A next attempt would need a predeclared, pinned Tier 1 panel with adjacent A/A gates and a same-input comparison before making a speed claim.
