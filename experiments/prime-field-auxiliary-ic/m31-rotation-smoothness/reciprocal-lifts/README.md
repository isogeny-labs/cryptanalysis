# Reciprocal alignment and affine lifts

Use all bound-89 nonsquare reciprocal rotation-orbit pairs in the frozen M31 census. For each unordered pair choose the orbit with smaller 31st-power key first, and enumerate its 31 representatives x. At phase j use y=2^j/x, j=0,...,30. Thus each phase visits exactly the same first and second coordinate populations. Report joint lift counts for the auxiliary curve y²=x³+x, the comparison curve y²=x³+2x+14, and its twist y²=x³+2x-14, counting a zero right-hand side as a lift. Record each comparison-curve joint count conditional on both coordinates lifting on the auxiliary curve, with the denominator. Phase zero is the preselected exact inverse phase. Compare it with the pooled rates and range over all 30 other cyclic alignments; no independence or random-sample assumption. This measures the finite smooth-orbit population only.
