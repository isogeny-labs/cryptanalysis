# Frozen M31 native inverse FFI collector comparison

Compare the current Rust four-lane Montgomery batch inversion inside `Curve<31>::batch_add_paired_x_filtered_assume_valid` with the existing `m31_batch_inverse` C++/ARM64 NEON implementation. Both arms keep identical M31 field and curve formulas after inversion, the same 500-point frozen auxiliary/plain public bases, 512 KiB high-bit x bitmap, exact sign-packed index, direct pair rows, deterministic walk, relation checks, elimination and generator answer check. The native library receives the 500 affine denominators for each paired batch and writes canonical inverses, including zero for exceptional denominators; Rust retains its existing exceptional-chord branch. Its ABI call and input/output conversion are inside timed collection.

Build both release binaries and the native static library before timing from pinned copies of the current Rust crate, Rust collector and existing `m31-field-ffi/m31.cpp`. Both binaries link the same library; only `M31_FFI_INV` differs. Before timing, run the existing native C ABI correctness checker against a shared build, audit candidate inverses on every nonzero denominator in one full run per basis/seed, require byte-identical complete sorted point-key/first-payload maps, and require equal basis digests, scalar, trials, relations and index entries in each matched block. A mismatch aborts the panel and is retained.

Use seeds 0, 1, 2 and eight balanced-order rounds per seed per basis (48 matched blocks, 96 fresh-process arms), shuffled with Python `random.Random(112587)`. Charge wall and parent-plus-child CPU from before basis regeneration through input writing, Rust process startup, table setup, relation collection, elimination, generator answer verification, parse and exit. Compilation, native ABI checks, frozen JSON loading and complete map audits precede timing. OS caches are not flushed. Report paired wall/CPU medians, wins and trial/row parity by basis, plus every failure/censor. Any gain requires a separate confirmation and independent signed review before adoption. Existing Lean arithmetic proofs apply to the standalone native field operations, not to the Rust FFI boundary or empirical runtime.
