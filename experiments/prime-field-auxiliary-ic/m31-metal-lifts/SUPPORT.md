# Ordered enumeration by prime support

Partition coordinates by the set of primes occurring in their factorization. Enumerate support masks in increasing order, inserting one copy of each prime into a base. Within a support, enumerate additional exponents with the largest prime varying fastest. Stop when the product exceeds the field representative bound. Since all remaining primes in the exponent loop are at least as large as the current prime, a failing first extension yields a single output. Check the complete ordered coordinate vector against the prior generator before timing.

Arm 0 is the previous combined SIMD generator; arm 1 uses serial support traversal. Arm 2 uses four host tasks writing disjoint ranges by largest prime. Compute the ranges inside each timed call by splitting primes into alternating groups, retaining sorted side products and counting complementary products by binary search. Arm 3 reuses just those offsets (one integer per boundary); this is a secondary amortized comparison. All four arms share the GPU pipeline, output capacity, fresh shared allocation, label dispatch and CPU count. Compare time and process CPU, including fresh range computation in arm 2. Two processes, sixteen balanced four-arm rounds with round −1 excluded. Every output word is checked. Replay using build.sh OUTPUT support and arguments 0 and 1.
