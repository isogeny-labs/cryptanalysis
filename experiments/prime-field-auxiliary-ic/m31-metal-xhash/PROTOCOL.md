# Frozen exact-x Metal screen comparison

Frozen on 2026-11-27 before the fresh timing panel. This is an opt-in factor-base hash experiment on the same five public M31 coordinates, B195 interval basis, four summands, 64 lanes, chunk 16384, 100000-query bound and 5 s online bound as the merged Metal collector. The control is its 20-bit bitmap; the candidate uses the 22-bit bitmap followed by a 131072-slot linear-probed exact x table on the GPU. Rust still performs exact point lookup, first-witness selection, relation checks, elimination and complete certificate verification. The table is built from the same pair points as the Rust index. The hypothesis is that exact x rejection eliminates most CPU candidate replay at modest GPU lookup cost.
