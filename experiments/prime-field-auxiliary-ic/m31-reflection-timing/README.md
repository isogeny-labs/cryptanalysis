# M31 fixed-target lift screening on one Apple M4 Pro

The reflected choice took 755 ms of aggregate wall time and the two-independent-set choice took 1,059 ms over 9,216 selections. Average lift counts were 17.595 and 17.609 respectively. The median paired wall-time speed ratio was 1.381, with a descriptive 95% block-bootstrap interval of [1.381, 1.429]. Reflection was faster in all 36 blocks. The one-set baseline took 545 ms and averaged 16.045 lifts. It produced 273 lifts per CPU millisecond, compared with 216 for reflection and 155 for the independent choice.

The target is fixed at y² = x³ + 2x + 14 over the field of 2³¹ − 1 elements. Each ordinary candidate contains the 32 auxiliary x-coordinates in a kernel coset. The reflected candidate negates those coordinates and evaluates the same target polynomial. Both selection arms score both candidates and keep the first on ties. All three arms construct actual affine target points for the chosen coordinates. The one-set baseline materializes directly. A reflected coordinate set has different algebraic structure from an ordinary kernel coset. Collector compatibility and relation yield require separate evidence.

The timed section includes class-coordinate generation, any candidate scoring, selected point construction, and counting the resulting list. Auxiliary initialization, class-index sampling, validation, and reporting are outside the clocks. Each arm uses the same first class per selection. Independent alternatives are disjoint sampled indices. All six arm orders occur six times over the 36 blocks of 256 selections. Warm-up used the first 32 pairs. The local host was shared, PARI/GP was version 2.17.3, and timers have millisecond resolution. This single-process setup measurement establishes no end-to-end improvement.
