# Lift frequency in fibers containing rotation-smooth coordinates

A mark means an eligible coordinate has a positive 47-smooth representative after some cyclic 31-bit rotation. The enumeration starts with all odd 47-smooth integers below p, deduplicates rotation orbits, and retains the full-order auxiliary coordinates by the existing two-character criterion. The total marked coordinates and their target lifts must agree with the independent coordinate census in ../m31-rotation-smoothness.

On the auxiliary curve y²=x³+x the fiber of a full-order point A consists of the x-coordinates of A+jK for the 32 multiples of the fixed order-32 step K. Use x([32]A) as the fiber identifier. Equality of identifiers means equality up to sign after multiplication by 32. The group identity in Tag.lean then gives membership in the same kernel translate up to sign. The base field auxiliary group is cyclic of order 2³¹, so this kernel is generated by K. Each newly identified fiber is traversed once and the program checks return to the starting point after 32 additions.

Build with clang++ -O3 -std=c++17 -Wall -Wextra -Werror census.cpp -o census and run ./census. The population contains 1760190 marked fibers and 28155874 target lifts within those fibers. Removing the marked coordinates leaves 27230476 lifts among 54473213 unmarked neighbors. The complementary fiber totals use the exhaustive population receipt in ../m31-lift-census. Tag.lean checks the exact comparison conditional on those counts. The traversal and counts are native computations.
