# Full M31 auxiliary fiber lift histogram

result.txt counts target lifts per 32-coordinate fiber on the auxiliary curve y²=x³+x at 2³¹−1, with target y²=x³+2x+14. For the full-order generator G=(3,615668188) and the subgroup generated by K=[2²⁶]G, the odd residues modulo 2²⁶ index full-order cosets. Taking x-coordinates identifies a coset and its negative. Coverage.lean proves the unique integer indexing up to sign. Fiber i starts at [2i+1]G; stepping by K visits its 32 coordinates. Adding [2]G to each of those points advances to the next fiber. The native traversal checks the initial orbit closes, the histogram has 2²⁴ entries counted with multiplicity, and its weighted sum agrees with the earlier, independent field census (268414441 lifts).

Build with clang++ -O3 -mcpu=native -std=c++17 -Wall -Wextra -Werror histogram.cpp -o histogram and run ./histogram. Lines prefixed with bin give lift count and fiber frequency. Lines prefixed with check give an index and its individual count. Run gp -q -f check.gp to reproduce all 64 check lines with independent point multiplication and quadratic characters.
