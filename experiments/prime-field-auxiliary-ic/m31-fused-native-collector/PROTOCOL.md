# Frozen M31 fused native candidate scan

Compare the selected 500-point Rust paired collector (512 KiB high-bit x bitmap) with a native C++ candidate scan on the same frozen public auxiliary/plain M31 fixtures. The candidate receives the current walk point and prevalidated signed base coordinates, computes paired denominators and their inverses with the existing ARM64 NEON `m31_batch_inverse`, computes both affine chord x coordinates, checks the same bitmap, and emits only bitmap-positive exact point keys with their signed base indices in increasing index order. Its slope and x arithmetic are scalar in this first screen. Rust retains the same first-payload exact index, relation equation checks, modular elimination, walk RNG and generator answer check. A zero denominator or identity walk point falls back to the Rust collector. Native invocation, conversions and fallback are charged.

Before timing, run the existing C ABI inverse checker, an independent Python point-addition check with an all-ones bitmap over all 1,000 signed candidates and an exceptional-denominator test, and an audit build that compares the native and Rust *first exact hit on every walk state* in full runs for seeds 0, 1 and 2 on both bases. Require byte-identical complete sorted point-key/first-payload maps and equal basis digest, scalar, trials, target relations and entries in each timed block. A mismatch aborts and is retained.

Use seeds 0, 1, 2 and eight balanced order rounds per seed per basis: 48 matched blocks, 96 fresh-process arms, shuffled with Python `random.Random(112593)`. Charge wall and parent-plus-child CPU from before basis regeneration through input writing, Rust process startup, table and bitmap setup, native scan calls, relation collection, elimination, generator answer verification, output parsing and exit. Compilation, fixture JSON loading and preflight checks precede timing; OS caches are not flushed. Report paired wall/CPU medians and wins by basis, native call and fallback counts, and all failures/censors. A gain requires a separately frozen confirmation and independent signed review before adoption. Existing Lean field proofs do not by themselves refine this FFI kernel or prove runtime.
