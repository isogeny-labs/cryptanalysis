# Tensor ranks and projected labels of M31 coordinates

The predicate is one when x³+2x+14 is a square, including zero, in the field of 2³¹−1 elements. Coordinates are unsigned 31-bit words. On the public field31_s5_base0 fiber, a four-bit projection gives every target lift label exactly. Bits are numbered from zero at the low end. Pack bits 5, 8, 15 and 26 into a four-bit key in that order and read that bit of 0x2a63. Of the 32 coordinates, 17 lift. Of the 16 possible keys, two do not occur on the frozen fiber. The displayed table assigns both zero.

Projection.lean evaluates the field predicate and projected table on the two disjoint lists, and checks a positive/negative collision for each of the 4,495 triples of bit positions. Any smaller projection can be extended to a triple. Thus four is the minimum number of raw coordinate bits for an exact lookup on these 32 inputs. An exhaustive search also found a second four-bit choice using bit 28 in place of bit 26. This representation assumes membership in the particular fiber. On 4,096 other distinct sampled fibers the frozen table matched 65,632 of 131,072 labels, while 65,687 coordinates lifted. The assignment to unused keys was held fixed.

For the unrestricted 31-bit predicate, consider the cut after 15 variables in ascending, descending and even-then-odd bit order. From the left positions choose nine spread across the 15, from the right positions choose ten spread across the remaining 16. Vary all 512 left assignments and the first 544 right assignments, setting all other bits to zero. At each cut the resulting 512-by-544 binary matrix has rank 512 over GF(2). Both the Euler-criterion Python implementation with XOR elimination and the PARI quadratic-character implementation with modular matrix rank reproduce this result.

For each tested order an exact field-valued tensor train factors this cut matrix through its middle dimension, which must therefore be at least 512. The same bound holds over the rationals and reals since a full-rank square minor modulo two has odd integer determinant. The result applies to these three orders and exact arithmetic tensor trains. Arbitrary circuits, approximate classifiers and untested bit orders require their own analysis.

Run `python3 ranks.py`, `gp -q -f ranks.gp </dev/null` and `gp -q -f transfer.gp </dev/null`. For the restricted-fiber certificate run Lean 4.28 with Mathlib on Projection.lean. These checks measure representation size and correctness, without timing a collector.
