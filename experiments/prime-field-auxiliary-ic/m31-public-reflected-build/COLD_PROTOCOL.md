# Cold public-table protocol

Frozen before measurement. Use the existing auxiliary and plain M31 fixtures,
500 representatives each, with the unchanged digest-checked Python references.
Run Rust flat and reflected paths in 24 matched blocks per basis. Keep the
existing seeded block shuffle and balanced execution order. Each observation
starts a new process with an empty table and no application-state reuse.

Measure parent-observed monotonic elapsed time from process launch through
successful exit, and child user plus system CPU time. This charges dynamic
loading, argument parsing, fixture reading, point checks, signed expansion,
allocation, table construction, reference reading and verification, output,
destruction and process exit. Retain the existing internal build timer.

The supplied basis is input. Generating a basis, regenerating Python validation
references, compiling the binary, and algebraic relation search/elimination
fall outside this public-table operation. OS file caches are not flushed.
Cold means fresh process/application state. Background host activity is allowed
and limits interpretation. Report medians, paired ratios and wins for wall and
CPU separately. Fail immediately on any rejected expected-valid fixture. Keep
all 96 observations and make no solver end-to-end speedup claim.
