Compare the same 500-representative frozen public M31 auxiliary and plain fixtures under the same sign-packed one-multiply index, validated paired-x batch arithmetic, direct pair rows, relation walk, and elimination. Control computes both y coordinates before exact point lookup. Candidate allocates a 2^20-bit (128 KiB) one-hash x-membership bitmap, marks every inserted x during charged table construction, and computes y only when the bitmap bit is set. False positives are allowed; false negatives are a correctness failure. The exact point lookup remains authoritative. The bitmap is a cache-resident prefilter, not a replacement for the index.

For each basis, seed 0/1/2 and eight balanced order rounds, regenerate and verify the basis inside each timed arm; use a fresh Rust process, charge input creation, table build, collection, elimination, answer verification, process exit, and parent-plus-child CPU. Compilation, frozen JSON load, complete sorted table-map audit and OS cache flushing are outside the timer. Require byte-identical sorted index maps and matched basis digest, scalar, trials, relations, entries in each pair. Shuffle seed 112541. Repeat with a different shuffle seed only if both bases improve in paired CPU and wall medians and identities match. Report all arms and any failures.
