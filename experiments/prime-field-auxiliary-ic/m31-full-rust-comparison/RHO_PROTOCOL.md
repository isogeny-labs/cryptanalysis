# Same-target cold M31 rho distance

Freeze before timing. Compare the current bitmap-combined Rust IC collector with the archived C++ Pollard rho control `snapshot/comparison/compare_rho.cpp`, both on the same public M31 point P and target Q in the auxiliary and plain fixtures. The two bases share P and Q; repeat the rho cells for each basis only to maintain paired order. This is the archived rho implementation, not a strongest-known or precomputed rho reference. Compile both binaries outside the timer from frozen source, with `FIELD_BITS=31` for rho and the candidate Rust flags from `BLOOM_DIRECT_PROTOCOL.md`. No retries or replacement cells.

For each basis, seeds 0/1/2, eight balanced order rounds, run one fresh candidate process and one fresh rho process. Candidate regenerates/checks its 500-point basis and charges all table, collection, elimination and verification work. Rho copies the frozen `public.txt` to a clean invocation directory inside its timer, parses it, performs the walk, verifies `[k]P=Q`, writes metrics and exits; the wrapper checks the reported scalar and metrics. Charge full wall and parent-plus-child CPU for both. Compilation, fixture JSON loading and source extraction are outside the timer. OS caches are not flushed. Use shuffle seed 112547. Retain all arms and failures. Report candidate/rho paired ratios separately from IC/IC improvement. The comparison uses different languages and a single local host; it is a distance indicator, not a proof of crossover.
