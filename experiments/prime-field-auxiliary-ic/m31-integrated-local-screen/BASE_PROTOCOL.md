# Integrated m2 basis-size screen

On the same frozen public M31 target, use the current `m31-fast` release
worker with coordinate-only input, interval factor base, signed m2 index,
64 lanes, four million query cap and five-second soft online cap. Run B =
128,256,384,512,768,1024 over seeds 0,1,2 in order shuffled by
`random.Random(2026112732)`. Charge fresh process wall and parent-plus-child
CPU, preserve full reports, statuses and phase costs, and verify every
recovered scalar against the public generator and target. Larger bases may
use more memory and setup; charge both. This same-target exploratory screen
locates a plausible B region. A promising size needs confirmation on fresh
targets and a matched rho panel before any performance claim.
