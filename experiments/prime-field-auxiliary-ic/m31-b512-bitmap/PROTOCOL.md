# Frozen native M31 B512 bitmap comparison

Hypothesis: at B512 the `PairIndex` currently disables its exact x prefilter, and enabling a 22-bit direct-high x bitmap can save failed HashMap probes enough to outweigh its cold construction cost. The candidate changes only the bitmap allocation and projection at B512. It retains every indexed x, the first and alternate pair witnesses, group arithmetic, factor base, walk, graph, and certificate path. The flag `M31_B512_BITMAP` is compile-time and opt-in.

Use p=2147483647, E:y²=x³+2x+14, n=2147505293, G=(1,814455902), five public Q and three independent walk seeds pinned in `SEEDS.json`. The target scalar is never passed to the solver. Run B512, m2, interval basis, 64 lanes, pair chunk 64, four-million query and five-second online caps. Three arms per target-seed block: current no-bitmap B512, candidate direct-high-22-bit B512, and archived same-target C++ rho. Shuffle the 15 blocks with the manifest schedule and rotate the arms as specified there. Build two Rust binaries from the same source commit, one without and one with `M31_B512_BITMAP`; compile before the clock. Fresh process per arm.

The external wall and parent-plus-child CPU clock begins before process launch and ends after JSON parsing, independent public answer multiplication and certificate-equation replay. Charge basis generation, pair-index setup, relation collection, graph elimination, internal certificate replay, final parsing and verification. Preserve complete raw stdout/stderr, exit status, failures, timeouts, source/binary hashes, host and CPU information. No completed-only timing summaries. Require exact answer, base digest, pair counts, query/row counts, certificate payload and every signed row to agree between paired Rust arms. A bitmap miss must be impossible for every retained x; a unit test exhausts all indexed entries and witnesses.

Selection gate: candidate must beat control on at least 12/15 paired blocks in both wall and CPU, with median paired control/candidate ratio at least 1.15 for both. Report same-panel rho distance. If it passes, freeze new seeds for confirmation before changing the default; if it fails, keep the candidate as an archived negative and remove opt-in production code. This local exploratory panel is not an isolated performance standing. Lean may establish payload preservation but cannot prove the timing result.
