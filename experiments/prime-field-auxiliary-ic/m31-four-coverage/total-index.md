# Full-coordinate validation at every slot

The four arms use the six-chunk fused XOR address with either 64 or 128 slots. The fused arms mark an empty slot with 17 and skip the full coordinate load there. The total arms replace this sentinel with index zero at construction, then always compare the complete coordinate before returning an index or miss. TotalIndex.lean proves exactness for any valid default index, assuming the table returns the correct index on stored keys.

Build total-index.cpp with Apple Clang 21.0.0 using -std=c++17 -O3 -mcpu=native. Feed the original-order /tmp/window-keys.txt generated by window-cost.md. The three Apple M4 Pro processes used seeds 16, 17 and 18. Every process checked the complete index output for every traversal. Each seed and condition contributed eight measured rounds after four warmups. Index construction and destruction were timed for every base. Each object's persistent size was 288 bytes for 64 slots and 352 bytes for 128, excluding base points and build scratch.

A separate untimed recount of the 1024-query all-miss streams gave the following occupied-slot counts per 4194304 probes.

| Seed | 64 slots | 128 slots |
|---|---:|---:|
| 16 | 1114472 | 556951 |
| 17 | 1116890 | 558313 |
| 18 | 1116243 | 557862 |

Always validating gives an additional setup pass in these measurements. The occupied-slot counts describe the source-level lookup condition; the comparison collected no CPU branch-miss or cache counters. The kernels operate on public synthetic query streams.
