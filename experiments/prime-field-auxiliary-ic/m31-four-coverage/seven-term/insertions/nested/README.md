# Nested insertion bound

From a mathlib environment, run `lake env python3 /absolute/path/to/replay.py`.
The script builds the pinned native census, recomputes the observations,
checks every row of rounds.csv, and asks Lean to verify the round counts
and their sum. The reference CSV used the full census. The replay uses
the sparse intersection mode in reverse generator order.

Start with the first 32 of the 74 core generators in frozen order. A gain
in five-term classes forces a row involving the new coordinate. When the
five-term count stays fixed, overlap exceeding the prior overlap plus 40
times the prior five-term class count forces a seven-term row by the
cancellation argument in the parent directory. Successful insertions in
one round have distinct private coordinates and vanish on each other's
private coordinates. If all fail, add the first pending generator for zero
rank credit. Each later round extends the span certified in earlier rounds.

The initial prefix has one five-term class. The 11 rounds certify 40
additional independent rows. Together with the 121 private coordinates
in the outer insertion study, this gives a conditional rank lower bound
of 162. The native finite counts and the five-term classification are
premises. The replay checks aggregate evidence and does not extract rows.

The same replay checks Round.lean and instantiates its ambient-space dimension
bound at the observed core rank and outer coordinate count. Given an independent
core family and one private-coordinate witness in the relation space per outer
insertion, the relation space has dimension at least 162. Replaying the counts
does not construct those row vectors in Lean.
