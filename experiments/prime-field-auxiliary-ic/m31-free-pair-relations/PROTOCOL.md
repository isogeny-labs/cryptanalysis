# Frozen M31 pair-table collision relation screen

Test a graph-theoretic reuse of the existing exact pair-sum index: whenever two distinct signed basis pairs have the same nonidentity group sum, their difference is a homogeneous four-term relation among factor-base logarithms. The control is the selected 500-point, 512 KiB high-bit bitmap Rust collector on each frozen public auxiliary and plain M31 fixture. The candidate records collision payloads during the same pair-table build, checks each equality by curve addition, forms the signed four-column row, and inserts independent rows into the same modular elimination matrix before the target walk. Keep first-payload index semantics, pair enumeration, curve arithmetic, walk RNG, target, and answer check unchanged. Report total duplicates, valid nonzero rows, homogeneous rank, and any invalid rows. A duplicate or a row count alone is not independent rank.

Compile control and candidate release binaries from one source copy, differing only by `M31_FREE_RELATIONS`. Before timing, regenerate both frozen 500-point bases, require byte-identical complete sorted point-key/first-payload maps, and check the public answer. Use seeds 0, 1, 2, eight balanced order rounds per seed per basis, and Python `random.Random(112581)` to shuffle 48 matched blocks (96 fresh-process arms). The target and basis match inside each block; trial and target-relation counts may differ because the candidate begins with homogeneous pivots. Retain every failure and censoring.

Charge wall and parent-plus-child CPU from before basis regeneration through input writing, table construction and collision harvest, pre-elimination, target relation collection, elimination, answer verification, output parse and process exit. Compilation, frozen fixture JSON loading and map audit precede timing; OS caches are not flushed. Compare paired full-pipeline wall and CPU medians, wins, table/harvest time, trial counts and free rank by basis. A performance gain needs both wall and CPU paired medians above one on both bases with identical public answers, then an independent confirmation. Existing binary-field work on free pair-root collisions reported low rank and a net cold loss; this M31 test makes no novelty or asymptotic claim. Local results remain unverified until independent signed review.
