# Wall time per qualifying M31 coordinate set

A candidate qualifies when at least t of its 32 coordinates lift on the fixed target. On a shared Apple M4 Pro with PARI/GP 2.17.3, reflection increased the throughput of qualifying sets at each of the four tested thresholds. At t = 20, the first panel took 0.321 ms per acceptance with reflection and 0.519 ms with a single candidate. The recorded four-arm replay took 0.378 and 0.631 ms respectively. Bootstrap intervals reflect within-panel block variation on one host. At t = 24 the single-candidate control accepted only 30 sets in the replay.

Every method generates the first candidate from an auxiliary coset. The single-candidate screening arm scores it and materializes it only if it qualifies. Both fallback arms stop at the first qualifying candidate. After an initial failure, the independent arm generates a second ordinary set, and the reflection arm scores the negated coordinates of the first set on the same target. The eager control in the four-arm panel materializes the first candidate before checking its size. Materialization creates one affine target point per liftable coordinate. No timing here includes downstream use of a selected set.

Each threshold uses 36 blocks of 256 attempts and all arms share their first candidate. The two panels use different deterministic class samples. Arm order changes between blocks and thresholds rotate within blocks. The sampling, curve initialization and warm-up are outside the clocks. CPU and wall clocks have millisecond resolution. Columns are block, threshold, arm (1 single screened, 2 independent fallback, 3 reflected fallback, 4 single eager), accepted sets, CPU ms and wall ms.

Run `python3 analyze.py` with NumPy to summarize the archived rows. Run `gp -q -f initial.gp </dev/null` or `gp -q -f panel.gp </dev/null` for new measurements. Run Lean 4.28 with matching Mathlib on BreakEven.lean for the general cost-per-acceptance criterion. The empirical timings and the setup-only scope remain separate from this algebraic proof.
