# Same-depth M31 public polynomial timings

The first model uses the frozen 17 coordinates. The second uses the first 17 of the third model's 20 liftable coordinates. The latter two share the same endpoint, 308674601, and belong to auxiliary class index 52 in the odd-multiple indexing of the lift census. All models have five maps. The inputs are public field elements, with no group walk. Timings cover the archived library's polynomial evaluation and its scan for zero outputs.

On the shared Apple M4 Pro, using Apple clang 21.0.0, the paired median dense-20/trimmed-17 time ratio was 1.1753 on native arm64, with a descriptive 95% block-bootstrap interval of [1.0729, 1.2487]. On the same machine using a translated x86_64 AVX2 binary, it was 1.0179 [0.9630, 1.0807]. The translated result describes Rosetta on this host. Absolute timings do not establish native x86 performance. The native arm64 build takes the archived scalar fallback. No timing here includes initialization, target generation, relation collection or verification.

The source pads the AVX2 evaluation to 12-coordinate tiles. Both sizes run two tiles, and the zero scan visits the logical number of coordinates. The scalar fallback evaluates each logical coordinate individually. Both binaries produced checksum 4645930646781192782 on all output lanes during validation. The harness checks common lanes for the nested sets on 8,192 inputs, then runs 36 blocks of 8,192 fresh inputs with all six arm orders balanced. CSV columns are block, arm (0 frozen, 1 trimmed, 2 dense), wall nanoseconds, and zero count.

From this directory, compile bench.cpp together with the archived optimized/native_v2.cpp as separate translation units using C++17, -O3 and -DBUILD_LIBRARY. Add -arch x86_64 -mavx2 for the translated build on macOS. Source SHA-256 for native_v2.cpp is 52c20890f4c920742e339c5c66e04b76b819604d913160ee8b63967e6e0aa341. Run each executable separately. The standard output contains CSV rows and the standard error contains the verification checksum. Run `python3 analyze.py` with NumPy to summarize the retained rows.
