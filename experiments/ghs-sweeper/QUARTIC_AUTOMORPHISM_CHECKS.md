# Prior-family discrimination by automorphisms, frozen 2026-10-25

Inputs: all 33 raw-verified +/-35 quartics from the completed O3 census.
Apply the published ordinary Fano-bitangent classification to compute every
geometric automorphism: transform to the split seven-bitangent model,
enumerate all 168 GL3(F2) matrices and test the full quartic polynomial up
to scalar. Conjugate accepted matrices back to the original coordinates
and replay the equation there using a separate field-valued substitution.

Check matrix and Galois closure, identity, element orders and the published
rational automorphism count (one except for the stated symmetric O3 models,
where it is three). Enumerate commuting involution pairs and identify V4
subgroups stable under q-Frobenius whose nonidentity elements form a 3-cycle.
The number of such subgroups among the targets is unknown before execution.

A positive row routes to Nart--Ritzenthaler arXiv:0905.0546, not to an
automatic novelty claim. The paper supplies Artin--Schreier covers of triples
and explicit elliptic quotients; an actual descended map to the selected
source curve remains to be constructed and checked. A negative row excludes
only that published V4 quotient route, not other covers or isogenies.
Retain all matrices, model identities, closures, raw commands, code hashes
and failures. This is exact algebraic verification, not a cost comparison.
