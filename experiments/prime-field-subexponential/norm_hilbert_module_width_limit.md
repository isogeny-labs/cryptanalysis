# Generic linear sections do not give a low-direction norm module

Let (A=S/I) be a finite homogeneous norm-convolution quotient and let
(B\subseteq A) be the subalgebra generated by linear forms
(\ell_1,\ldots,\ell_k). Every generating set for (A) as a (B)-module
maps to a spanning set of

\[
 A/B_+A=A/(\ell_1,\ldots,\ell_k).
\]

Therefore every such module presentation needs at least
(\dim A/(\ell_1,\ldots,\ell_k)) generators. This bound applies even when
the action of each generator is stored implicitly.

Three random nested flags in every deterministic quotient of dimensions
3 through 9 give exactly the iterated positive differences of the original
Hilbert function. For example, the dimension-nine quotient starts with

\[
 (1,9,34,66,55,1).
\]

After one, two, and three generic linear forms the measured Hilbert functions
are respectively

\[
 (1,8,25,32),\qquad (1,7,17,7),\qquad (1,6,10),
\]

so the corresponding module-generator lower bounds are 66, 32, and 17.
Every one of the 105 measured section profiles matches the maximal-rank
prediction.

## Semi-regular scaling model

For (r+2) semi-regular quadrics in (r) variables, quotienting by (k)
generic linear forms gives the positive part of

\[
 \frac{(1-t^2)^{r+2}}{(1-t)^{r-k}}
  =(1+t)^{r+2}(1-t)^{k+2}.
\]

The normalized base-two logarithms of the resulting generator bounds are:

| (r) | (k=0) | (k=r/4) | (k=r/2) | (k=3r/4) | (k=7r/8) |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 32 | 0.8997 | 0.5108 | 0.2691 | 0.1081 | 0.0726 |
| 64 | 0.9356 | 0.5029 | 0.2530 | 0.1007 | 0.0495 |
| 128 | 0.9603 | 0.4967 | 0.2416 | 0.0870 | 0.0353 |
| 256 | 0.9763 | 0.4889 | 0.2286 | 0.0780 | 0.0322 |

Thus every tested fixed positive fraction of remaining directions retains an
exponential module width. Taking only (\lfloor\sqrt r\rfloor) remaining
directions makes the model width subexponential, but requires putting
(r-O(\sqrt r)) independent linear operators into the base algebra. This is
not a compression unless their simultaneous relations can be processed
without restoring the original state space.

## Exact limit

The generator inequality is unconditional. The finite-section profiles are
exact over (\mathbb F_{101}). The scaling table is a semi-regular model, not
an asymptotic theorem about the norm ideals. It does not rule out a succinct
simultaneous representation of nearly all multiplication operators, nor an
elimination algorithm that is not a module presentation. No DLP exponent
improvement is claimed.
