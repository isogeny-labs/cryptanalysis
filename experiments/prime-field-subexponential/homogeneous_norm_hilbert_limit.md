# Homogeneous norm Hilbert-function boundary

The affine Macaulay boundary calculation leaves one plausible escape: keep the
quadratic norm equations homogeneous, propagate their low-displacement
recurrence by exact degree, and avoid the dehomogenized top boundary.  This
control measures the size of that homogeneous quotient before attempting a
structured solver.

For projective section dimension $r$, fix the same affine chart as the split
norm controls and retain only the degree-two part of each of the $r+2$
non-leading norm coefficients. If these forms generate
$I_r\subset\mathbb F_{101}[z_1,\ldots,z_r]$, the script computes

\[
  H_r(d)=\dim_{\mathbb F_{101}}(\mathbb F_{101}[z_1,\ldots,z_r]/I_r)_d
\]

by exact modular row reduction in every degree through the first zero.  The
panels for $r=1,\ldots,7$ are the frozen split-norm fixtures. The $r=8,9$
panels are seeded planted divisors generated by the same construction used in
the span-state control.

The measured functions are

| $r$ | exact $H_r(d)$, through zero | semi-regular prediction |
| ---: | --- | --- |
| 1 | 1, 1, 0 | 1, 1, 0 |
| 2 | 1, 2, 0 | 1, 2, 0 |
| 3 | 1, 3, 1, 0 | 1, 3, 1, 0 |
| 4 | 1, 4, 4, 0 | 1, 4, 4, 0 |
| 5 | 1, 5, 8, 1, 0 | 1, 5, 8, 0 |
| 6 | 1, 6, 13, 8, 0 | 1, 6, 13, 8, 0 |
| 7 | 1, 7, 19, 21, 1, 0 | 1, 7, 19, 21, 0 |
| 8 | 1, 8, 26, 40, 16, 0 | 1, 8, 26, 40, 15, 0 |
| 9 | 1, 9, 34, 66, 55, 1, 0 | 1, 9, 34, 66, 55, 0 |

Thus the curve-derived ideals match the coefficientwise truncated
semi-regular series

\[
  \left[\frac{(1-t^2)^{r+2}}{(1-t)^r}\right]_+
\]

exactly or differ by only one class in these nine panels. The structured
syzygies visible here are too small to collapse the graded state space.

The degree-six vanishing for $r=9$ is certified without materializing its
3,003-column Macaulay matrix. Since the degree-five quotient has dimension
one, multiplication presents the next component with nine generators.
Relations obtained by giving each degree-six monomial all of its possible
variable factorizations have rank nine, so the next component is zero. This
quotient propagation is an exact implementation improvement, but it acts only
after the quotient has already reached constant size.

For orientation only, the executable ledger evaluates the semi-regular model
at $r=8,16,32,64,128$. Its base-two logarithm of total quotient length,
divided by $r$, is respectively 0.8115, 0.8559, 0.8997, 0.9356, and 0.9603.
This model therefore predicts an exponentially large explicit quotient, not a
subexponential Macaulay representation.

## Exact limit

This is a finite rank computation over one prime and one panel per dimension;
it is not an asymptotic Hilbert-series theorem or a lower bound on structured
algorithms. The larger-$r$ rows are only semi-regular model values. A
positive route could still manipulate the homogeneous ideal implicitly using
the rank-four displacement recurrence.  It must, however, avoid materializing
the measured graded quotient and prove that its implicit representation and
all downstream operations have $p^{o(1)}$ cost. No exponent improvement is
claimed here.
