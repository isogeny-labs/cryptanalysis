\section*{Independent GLV table-selector review}
\textbf{2026-11-07.} Eight named theorems compile under pinned Lean 4.34.1. For the same nonnegative input and positive log factor, changing the budget divisor from 48 to 12 cannot decrease the selected 8/16/32 table size. This is a conditional selector-arithmetic result.
