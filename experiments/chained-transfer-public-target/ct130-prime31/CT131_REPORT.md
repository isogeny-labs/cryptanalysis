# CT131 — Isogeny to a CM automorphism model: measured toy rho screen

**2026-11-15 · [pcc:unverified] · local producer-only; scoped independent arithmetic audit, not signed PCC or fastest-source comparison.**

## Research result

We found a fixed ordinary prime-field elliptic curve E with j(E)=287496 and a rational **degree-2** DLP-preserving map to an isogenous j=1728 curve T. The prime-order subgroup is preserved (q=536857417, gcd(2,q)=1). The target has a **four-element automorphism orbit** generated by (x,y)->(-x,i*y), where i^2=-1 mod p, with known eigenvalue lambda^2=-1 mod q. The source only has its intrinsic negation as a degree-1 automorphism. This is the classical CM/GLV mechanism, not a new asymptotic DLP reduction or an unrecognized generic prime-field attack.

The following costs are **observed** from two same-host post-correction ABBA/BAAB cohorts, 64 public source scalar fixtures each (128 distinct targets, 256 timed source and 256 timed target solves). In each timed run, the solver received *public G,Q only*; planted k was used for subsequent independent verification. All recovered source logarithms were correct. Target-arm timing includes mapping G,Q, jump generation, random walk, fruitless-cycle escape and source verification. Both arms use the same Python affine rho kernel and all-state dictionary. No paid compute was used.

The **pooled operation-count ratio** is 3,191,600 / 2,352,072 = **1.3569x** fewer source-equivalent group-add calls per target solve using the target fourfold quotient. Elapsed time improves less because target canonicalization is more expensive per step and because the same-host timing is noisy.

A simple target-level paired bootstrap gave a *diagnostic, not confirmatory* pooled aggregate speed ratio interval of **1.005–1.268** (20,000 resamples). It assumes exchangeability across 128 fixtures and ignores between-process/host uncertainty; it is **not** admissible independent uncertainty. The two separate cohorts disagree markedly (1.026 vs 1.230), and the first is effectively at the A/A noise floor. These data **do not establish a reliable complete-solver advantage**. A fresh same-host native rho/BSGS/IC comparison and independently signed PCC are required.

## Mathematical proof obligations and checked identities

Write p=2147483033 (prime), q=536857417 (prime). Let a=622683939, b=2147483024, r=969960860. E: y^2=x^3+a*x^2+b*x; T:y^2=x^3+9*x. The explicit public source-to-target map is

> F(x,y)=(r + (x+a+b/x)/4, y(1-b/x^2)/8) mod p,

with F(O)=O and F((0,0))=O, where divisions are field inverses. This is a normalized two-isogeny followed by the coordinate scaling/translation of its dual. Check F(G)=H and F([k]G)=[k]H, including k=1,2,13,137,123456,7654321,q-1. The target has rational 2-torsion (0,0),(r,0),(-r,0), so 4 divides #T. The prime-order H has [q]H=O; Hasse's interval contains only one multiple of 4q, yielding #T(Fp)=4q. Isogeny gives #E(Fp)=4q. On target i=392507391 with i²=-1 mod p; lambda=390258842 with lambda²=-1 mod q and [-x,i*y]=[lambda] on H. Every returned source k is checked with [k]G=Q.

The map and the CM representation are special **to this source family**. A random NIST curve is not asserted to admit this cheap CM-neighbor route. Given any fixed isogeny, one may construct a source-side endomorphism by conjugation, but its per-step cost (additional isogeny evaluations) must be charged.

## Controls and failures

- Original 8-case pilot showed mixed ratios; omitted from holdout. An exploratory 8-case GLV-orbit BSGS study failed to produce a consistent advantage, so BSGS is not promoted.
- Initial uncorrected holdout outputs did **not** expose the recovered scalar and had only one timing per arm. This is a scientific audit defect; those outputs, source/protocol hashes and measured ratios are retained separately. A source-only correction exposed k and added ABBA/BAAB A/A repeats before rerunning both holdouts. The first protocol was locally hash-frozen, **not remotely preregistered**.
- The independently implemented auditor re-derives the public point, F(Q), group order proof, lambda action, every log, all 256 per-arm samples, operation counts and deterministic A/A signatures. Eight distinct corruptions on each raw cohort (16 total) are rejected in normal and Python -O modes. This is **same-session independent code**, not an independent human/CI signature.
- A standalone, shorter repo entrypoint uses the CT130 affine arithmetic and matched *all non-timing walk trajectories, operation counts and public outputs on eight fixed holdout targets* against the local executed prototype. The remote committed bytes have not been rerun on an isolated checkout.
- The local container lacks Cargo/Rust and cannot access a complete repository checkout; no native CT126 C169, C13a, C13b, D, full 701-record chain or matched rho/IC cost is inferred from this result.
- No stronger external rho, rootfinding IC, GPU matched solve, field construction, PCC signature, CI success, independent host or full group/Jacobian cold setup was measured. No speedup/leaderboard admission, auto-merge or paid EKS launch.
