## Recorded finding and its scope

**Theorem (source fiber).** Let `p>5` be prime, let `C/F_p` be `y²+y=x³−7`, and use the rational source-`j` map fixed in the [coordinate bridge](../../experiments/hecke-27-coordinate-bridge-20261025/coordinate_map.json). If `3` is a nonsquare in `F_p`, there is no point of `C(F_p)` at which that map is defined and has value `1728`. Equivalently, the rational source fiber is empty for every prime `p>5` with `p ≡ 5` or `7 (mod 12)`. An exact resultant identity, an integer `√3` witness, and direct audits of the three denominator exceptions prove the statement.
