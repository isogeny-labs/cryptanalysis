### Decisions made (and why)
- `-ffp-contract=off` always, not only with `CA_ARCH`: aarch64 builds have FMA at the baseline level too.
- `-mno-mmx` with any named level on GCC/x86-64: GCC 13.3 at SSE4.1-without-AVX emits an MMX move without EMMS in `ec_tau.c`, which hangs `test_curve` through `ca_isqrt`'s `sqrtl`; no source uses MMX.
- `CA_LTO` default OFF: instruction counts move −0.1 % … +0.3 % on the five non-emulator kernels, the build takes about 3× as long, and the static archive needs fat objects. `-fno-semantic-interposition` not added: it breaks the `CA_WERROR` build with `-Wmaybe-uninitialized` in `src/modarith.c`.
- `CA_GPU_PTX_MONT` and `CA_GPU_SMEM_TABLE` default OFF: neither can be run without a GPU; the original kernel's name and signature are kept for the Rust binding.
- Not done: SoA walk state (layout read by `tests/test_gpu.c`, loaded once per launch of ≥ 64 steps), double-buffered DP launches (changes restart timing, so the walks), C11 warp-cooperative inversion (no issued-instruction reduction on SIMT).
