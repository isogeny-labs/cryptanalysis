- `CA_GPU_PTX_MONT` and `CA_GPU_SMEM_TABLE` default OFF: neither can be run without a GPU; the original kernel's name and signature are kept for the Rust binding.
- Not done: SoA walk state (layout read by `tests/test_gpu.c`, loaded once per launch of ≥ 64 steps), double-buffered DP launches (changes restart timing, so the walks), C11 warp-cooperative inversion (no issued-instruction reduction on SIMT).
